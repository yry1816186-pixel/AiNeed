# Quick Task 260426-p72: 统一色彩体系 — 将 Colors / flatColors / colors 合并为单一 DesignTokens 源 - Plan

**Created:** 2026-04-26
**Status:** Completed

## Problem

三套色彩体系并行导致色值不一致：

1. `Colors` (theme/index.ts) — 带色阶的派生对象
2. `flatColors` / `colors` (theme/index.ts) — 扁平化便捷层，含硬编码色值
3. `colors` (tokens/colors.ts) — 品牌色组合，不响应暗色模式

关键不一致：

- `PrimaryColors` vs `Colors.primary` 色阶值不同（如 100 阶 #FAF0EA vs #FAEDE6）
- `WarmPrimaryColors` vs `theme/index.ts` 中的 oceanPalette/mintPalette/coralPalette 值不同
- `flatColors` 中 15+ 处硬编码 hex 值未通过 DesignTokens 引用
- 渐变键 warm/cool/hero 在 flatColors 中静默覆盖 DesignTokens 定义

## Tasks

### Task 1: 统一 PrimaryColors/SecondaryColors 色阶

- **files**: tokens/colors.ts, theme/index.ts
- **action**: 以 Colors.primary/Colors.sage 为准更新 PrimaryColors/SecondaryColors，然后让 Colors.primary/sage 从 PrimaryColors/SecondaryColors 派生
- **verify**: PrimaryColors[100] === Colors.primary[100]
- **done**: ✅ 色阶统一，Colors.primary = PrimaryColors, Colors.sage = SecondaryColors

### Task 2: 统一 WarmPrimaryColors 色阶

- **files**: tokens/colors.ts
- **action**: 更新 WarmPrimaryColors 的 coral/mint/ocean 色阶值与 theme/index.ts 中的 oceanPalette/mintPalette/coralPalette 一致
- **verify**: WarmPrimaryColors.coral[500] === coralPalette[500]
- **done**: ✅ WarmPrimaryColors 已与 warmPrimary palettes 统一

### Task 3+4: 消除 flatColors 硬编码 + 补充 DesignTokens

- **files**: design-tokens.ts, theme/index.ts, FlatColors.ts

- **verify**: buildFlatThemeColors() 中无硬编码 hex 值
- **done**: ✅ 所有硬编码已替换为 DesignTokens 引用

### Task 5: 标记 tokens/colors.ts 的 colors 导出为 deprecated
