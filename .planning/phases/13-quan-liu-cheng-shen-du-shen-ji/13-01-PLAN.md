**Step 3: Create `scripts/audit/screenshot-capture.ts`** — Playwright screenshot script:

```typescript
import { chromium } from "playwright";
import { SCREEN_REGISTRY } from "./screens";
import * as fs from "fs";
import * as path from "path";
```

The script should:

1. Create output directories: `.planning/audit/screenshots/{tab}/` for each tab
2. Launch Chromium in headless mode
3. Start Expo Web dev server (run `npx expo start --web --port 8082` as a child process, wait for it to be ready)
4. For each screen in SCREEN_REGISTRY:
   a. If `nativeOnly` is true, skip with a log entry (mark for manual capture)
   b. Navigate to the URL path
   c. Wait for the page to stabilize (network idle or 3s timeout)
   d. If `requiresAuth` is true, first navigate to login, fill in test credentials, then navigate to target
   e. Take screenshot with `page.screenshot({ fullPage: true })`
   f. Save to `.planning/audit/screenshots/{tab}/{id}.png`
5. Generate a summary JSON: `{ captured: number, skipped: number, total: number, skippedScreens: string[] }`
6. Close browser and dev server

For auth bypass: Use test credentials from `.env.test` or environment variable `TEST_USER_EMAIL` / `TEST_USER_PASSWORD`. If not available, log a warning and capture the login screen only.

For screens that require specific data state (e.g., a recommendation detail), navigate to the parent screen first and click the first available item.

Error handling: If a screen fails to load, log the error and continue. Do not abort the entire run.

Add `--base-url` CLI flag to override the default `http://localhost:8082`.
Add `--filter` CLI flag to capture only matching screen IDs (comma-separated).
