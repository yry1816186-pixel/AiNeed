**Step 1: Create `scripts/audit/component-audit.ts`**

The script scans all `.tsx` files in `apps/mobile/src/features/` and `apps/mobile/src/design-system/` and `apps/mobile/src/shared/` and `apps/mobile/src/components/` for:

1. **Hardcoded colors** — Regex: `#[0-9A-Fa-f]{3,8}(?![0-9A-Fa-f])` and `rgb[a]?\(` in style objects

   - Exception: colors that match token values (from design-tokens.ts) are OK
   - Exception: colors in comments and string literals (non-style context)

2. **Hardcoded spacing** — Regex: numeric values in `margin`, `padding`, `gap`, `top`, `left`, `right`, `bottom`, `width`, `height` that don't correspond to the token scale (0, 1, 2, 4, 6, 8, 10, 12, 14, 16, 20, 24, 28, 32, 36, 40, 44, 48, 56, 64, 80, 96, 128)

   - Exception: values of 0, 1 (border width), 100% are OK
   - Exception: values in design-system/theme/tokens/ files themselves

3. **Hardcoded border radius** — Regex: `borderRadius:\s*\d+` where the value is not in token scale (0, 2, 4, 6, 12, 16, 24, 32, 9999)

4. **Hardcoded font sizes** — Regex: `fontSize:\s*\d+` where the value is not in token scale (10, 11, 12, 14, 16, 18, 20, 24, 30, 36, 48, 60)

5. **Inconsistent animation patterns** — Look for:

   - `Animated.timing` with `duration:` values not matching token durations (100, 200, 300, 500, 800)
   - `withTiming` with non-standard durations
   - Direct `useNativeDriver` usage (should use centralized animation system)

6. **Missing accessibility** — Count:
   - Interactive elements (`TouchableOpacity`, `Pressable`, `Button`) without `accessibilityLabel`
   - Images without `accessibilityLabel` or `alt`
   - Touch targets with explicit height/width < 44

For each finding, output:

```
{file}:{line} | {category} | {value} | {suggestion}
```

Categories: HARDCODED_COLOR, HARDCODED_SPACING, HARDCODED_RADIUS, HARDCODED_FONT, INCONSISTENT_ANIM, MISSING_A11Y
