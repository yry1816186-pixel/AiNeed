# Plan 20-01: Docker 化全栈环境

## Objective

创建 docker-compose.local.yml 实现一条命令启动 PostgreSQL + Redis + MinIO + Qdrant + FastAPI AI Service + NestJS Backend，确保 Prisma migrate 可执行。

<name>Create docker-compose.local.yml with all services</name>

<action>
Create `docker-compose.local.yml` in project root with these services:

1. **postgres** — Copy from docker-compose.dev.yml, use env vars: POSTGRES_USER=xuno, POSTGRES_PASSWORD=postgres, POSTGRES_DB=xuno. Health check: pg_isready.

2. **redis** — Copy from docker-compose.dev.yml, command with --requirepass redis123. Health check: redis-cli ping.

3. **minio** — Copy from docker-compose.dev.yml, ports 9000+9001. Health check: curl /minio/health/live.

4. **qdrant** — Copy from docker-compose.dev.yml, ports 6333+6334. Health check: TCP check.

5. **minio-init** — Copy from docker-compose.dev.yml. Creates xuno bucket.

   - AI_SERVICE_HOST=0.0.0.0
   - AI_SERVICE_PORT=8002

   - QDRANT_URL=http://qdrant:6333
   - GLM_API_KEY=${GLM_API_KEY:-}
   - ZHIPU_API_KEY=${ZHIPU_API_KEY:-}
   - OPENAI_API_KEY=${OPENAI_API_KEY:-}
     Ports: 8002:8002. Depends_on: redis (healthy), qdrant (healthy). Health check: curl http://localhost:8002/health.

7. **backend** — Build from context: ., dockerfile: apps/backend/Dockerfile. Environment:
   - NODE_ENV=development
   - DATABASE_URL=postgresql://xuno:postgres@postgres:5432/xuno?schema=public
   - REDIS_URL=redis://:redis123@redis:6379
   - JWT_SECRET=dev-jwt-secret-local-not-for-production
   - JWT_REFRESH_SECRET=dev-jwt-refresh-secret-local-not-for-production

   - MINIO_ACCESS_KEY=minioadmin
   - MINIO_SECRET_KEY=minioadmin123

   - AI_SERVICE_URL=http://ai-service:8002
   - ML_SERVICE_URL=http://ai-service:8002

   - GLM_API_ENDPOINT=${GLM_API_ENDPOINT:-https://open.bigmodel.cn/api/paas/v4}

<action>
1. Verify `apps/backend/Dockerfile` exists. If it does not exist, create it:
```dockerfile
FROM node:20-alpine AS base
RUN corepack enable
WORKDIR /app

FROM base AS deps
COPY package.json pnpm-lock.yaml pnpm-workspace.yaml ./
COPY apps/backend/package.json ./apps/backend/
COPY packages/shared/package.json ./packages/shared/
RUN pnpm install --frozen-lockfile

FROM base AS builder
COPY --from=deps /app/node_modules ./node_modules
COPY --from=deps /app/apps/backend/node_modules ./apps/backend/node_modules
COPY --from=deps /app/packages/shared/node_modules ./packages/shared/node_modules
COPY . .
RUN cd apps/backend && npx prisma generate && pnpm build

FROM base AS runner
COPY --from=builder /app/apps/backend/dist ./dist
COPY --from=builder /app/apps/backend/prisma ./prisma
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/apps/backend/node_modules ./apps/backend/node_modules
COPY --from=builder /app/apps/backend/package.json ./apps/backend/
COPY --from=builder /app/packages/shared ./packages/shared

WORKDIR /app/apps/backend
EXPOSE 3001
CMD ["sh", "-c", "npx prisma migrate deploy && node dist/main.js"]

````

```dockerfile
COPY services/ ./services/
EXPOSE 8002
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8002"]
````
