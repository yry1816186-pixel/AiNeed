<!-- WatermelonDB API surface (from RESEARCH.md verified against npm registry v0.28.0) -->

- Database(adapter, modelClasses) - 初始化
- SQLiteAdapter({ schema, dbName, jsi }) - SQLite 适配器
- appSchema({ version, tables: [tableSchema({ name, columns })] }) - Schema 定义
- Model subclass - table association + field decorators @field @date @relation
- database.get<T>(tableName).query(Q.where(...), Q.sortBy(...), Q.take(N)) - 查询
- database.get<T>(tableName).find(id) - 按主键查找
- database.write(async () => { database.batch(...) }) - 批量写
- query.observe() - RxJS 响应式查询
- synchronize({ database, pullChanges, pushChanges }) - 同步 API

<!-- Backend API endpoints for sync (explicit URLs for syncEngine) -->

- GET /api/v1/recommendations?limit=50 — pull latest 50 recommendations for offline cache
- POST /api/v1/wardrobe/sync — push dirty wardrobe items and pull latest from server (request body: { items: [{ server_id, section, item_json, is_dirty }] })
- GET /api/v1/calendar?days=7 — pull 7-day calendar plans
- GET /api/v1/user/profile — pull current user profile for offline access

<threat_model>

## Trust Boundaries

| Boundary                           | Description                                            |
| ---------------------------------- | ------------------------------------------------------ |
| API -> WatermelonDB cache          | Data from server stored locally; stale data possible   |
| Offline user actions -> sync queue | Local modifications queued for sync; conflict risk     |
| NetInfo state -> UI                | Network state drives UX; false offline/online possible |

## STRIDE Threat Register

| Threat ID | Category               | Component                | Disposition | Mitigation Plan                                                             |
| --------- | ---------------------- | ------------------------ | ----------- | --------------------------------------------------------------------------- |
| T-10-08   | Tampering              | Local SQLite data        | accept      | Device-rooted users could modify local DB; no financial data cached         |
| T-10-09   | Denial of Service      | Sync engine on reconnect | mitigate    | Batch sync operations; limit concurrent sync requests                       |
| T-10-10   | Information Disclosure | Cached user profile      | mitigate    | No raw passwords/tokens in WatermelonDB; profile_json contains non-PII only |

</threat_model>
