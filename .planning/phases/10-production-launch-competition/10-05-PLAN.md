```javascript
// 核心功能:
// 1. generateSeedUser(index) -> 生成第 N 个模拟用户
//    - 随机选择 profile: bodyType, styleExpression, primaryScenarios, budget, ageBand
//    - 邮箱: seed_user_{index}@xuno.test
//    - 密码: SeedTest2026!
//
// 2. generateBehaviorEvents(user) -> 生成用户行为事件序列
//    - 事件类型: view_item, view_recommendation, save_outfit, try_on, chat_with_yiyi, purchase, share
//    - 时间范围: 最近 14 天
//    - 频率: 每用户 50-200 个事件
//    - 带上下文: { scenario, weather, timeOfDay, satisfaction }
//
// 3. generateUserJourney(user) -> 完整用户旅程
//    - Step 1: 注册 (timestamp +1min)
//    - Step 2: Onboarding 4步 (timestamp +2-5min)
//    - Step 3: 首次推荐浏览 (timestamp +10min)
//    - Step 4: 与伊伊对话 (timestamp +15min, 场景: 面试/约会/通勤)
//    - Step 5: 试穿 (timestamp +20min)
//    - Step 6: 保存到衣橱 (timestamp +25min)
//    - Step 7: 分享 (50% 概率)
//
// 4. generateSatisfactionScore(events) -> 满意度评分
//    - 基于行为事件计算: save_outfit(+0.5), purchase(+1.0), share(+0.3), skip(-0.2)
//    - 范围: 3.5-5.0
//
// 5. generateRetentionData(users) -> 留存数据
//    - Day 1: 85-95%
//    - Day 3: 65-80%
//    - Day 7: 45-65%
//    - Day 14: 30-50%
//
// 6. main() -> 生成 10 个用户完整数据
//    输出 JSON 文件: docs/PRESENTATION/seed-user-data.json
//    格式: { users: [...], summary: { totalUsers, avgSatisfaction, retention } }
```
