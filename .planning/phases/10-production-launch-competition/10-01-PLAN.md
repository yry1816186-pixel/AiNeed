1. 修改 nginx.conf:

a. 在 http 块最外层 (server 块之前) 添加 rate limiting zone 定义:

```
limit_req_zone $binary_remote_addr zone=api_limit:10m rate=30r/m;
limit_req_zone $binary_remote_addr zone=ai_limit:10m rate=10r/m;
```

b. 更新 TLS 证书路径: 将 ssl_certificate 和 ssl_certificate_key 从 xuno.ai 改为 xuno.cn:

- ssl_certificate /etc/letsencrypt/live/xuno.cn/fullchain.pem;
- ssl_certificate_key /etc/letsencrypt/live/xuno.cn/privkey.pem;

c. 在 location /api/ 块内 (proxy_pass 之前) 添加:

```
limit_req zone=api_limit burst=20 nodelay;
limit_req_status 429;
```

d. 在 location /ai/ 块内 (proxy_pass 之前) 添加:

```
limit_req zone=ai_limit burst=5 nodelay;
limit_req_status 429;
```

e. 添加 Grafana 代理 (监控栈是比赛技术展示亮点):

```
location /grafana/ {
    proxy_pass http://grafana:3000/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

2. 创建 infrastructure/scripts/deploy-production.sh (确保目录存在):

   ```bash
   #!/bin/bash
   # 寻裳 XUNO 生产部署脚本
   set -euo pipefail
   SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
   PROJECT_ROOT="$(cd "$SCRIPT_DIR/../.." && pwd)"

   echo "=== 寻裳 XUNO 生产部署 ==="
   echo "目标: 4C8G 腾讯云轻量应用服务器"
   echo ""

   # 1. 检查 secrets 目录
   if [ ! -d "$PROJECT_ROOT/secrets" ]; then
       echo "创建 secrets 目录..."
       mkdir -p "$PROJECT_ROOT/secrets"
   fi

   # 2. 检查 .env.production
   if [ ! -f "$PROJECT_ROOT/.env.production" ]; then
       echo "错误: .env.production 不存在"
       echo "请复制 .env.production.example 并填写实际值"
       exit 1
   fi

   # 3. 验证必要 secrets 文件
   for secret in jwt_secret database_url openai_api_key fal_api_key; do
       if [ ! -f "$PROJECT_ROOT/secrets/${secret}.txt" ]; then
           echo "警告: secrets/${secret}.txt 不存在"
       fi
   done

   # 4. TLS 证书检查
   if [ ! -d "/etc/letsencrypt/live/xuno.cn" ]; then
       echo "警告: TLS 证书不存在，启动 certbot 获取..."
       # certbot 获取逻辑 (需要域名 DNS 已解析)
   fi

   # 5. 拉取最新镜像
   echo "拉取 Docker 镜像..."
   docker compose -f "$PROJECT_ROOT/docker-compose.production.yml" pull

   # 6. 启动服务
   echo "启动生产服务..."
   docker compose -f "$PROJECT_ROOT/docker-compose.production.yml" up -d

   # 7. 等待健康检查
   echo "等待服务健康检查..."
   sleep 30

   # 8. 验证部署
   echo "=== 部署验证 ==="
   docker compose -f "$PROJECT_ROOT/docker-compose.production.yml" ps
   echo ""
   echo "内存使用:"
   docker stats --no-stream --format "table {{.Name}}\t{{.MemUsage}}"
   echo ""
   echo "=== 部署完成 ==="
   echo "API: https://xuno.cn/api/v1/health"
   echo "Grafana: https://xuno.cn/grafana/"
   ```

<threat_model>

## Trust Boundaries

| Boundary                           | Description                                                      |
| ---------------------------------- | ---------------------------------------------------------------- |
| Internet -> Nginx (443)            | Untrusted traffic enters here; rate limiting and TLS termination |
| Nginx -> Backend (3001)            | Internal network; backend trusts Nginx headers                   |
| Nginx -> AI Service (8002)         | Internal; AI endpoint has stricter rate limit                    |
| Backend -> PostgreSQL/Redis/Qdrant | Internal only; no external access                                |
| Secrets files -> Containers        | Docker Secrets mounted read-only                                 |

## STRIDE Threat Register

| Threat ID | Category               | Component                  | Disposition | Mitigation Plan                                              |
| --------- | ---------------------- | -------------------------- | ----------- | ------------------------------------------------------------ |
| T-10-01   | Denial of Service      | Nginx /api/ endpoint       | mitigate    | rate limiting 30r/m burst=20; return 429 when exceeded       |
| T-10-02   | Denial of Service      | Nginx /ai/ endpoint        | mitigate    | rate limiting 10r/m burst=5; stricter for AI endpoints       |
| T-10-03   | Information Disclosure | TLS certificate            | mitigate    | Let's Encrypt auto-renewal; TLS 1.2+ only                    |
| T-10-04   | Elevation of Privilege | Docker exposed ports       | mitigate    | all services use expose not ports; only Nginx publishes 443  |
| T-10-05   | Spoofing               | JWT secret exposure        | mitigate    | Docker Secrets files not env vars; secrets/ gitignored       |
| T-10-06   | Denial of Service      | Memory exhaustion          | mitigate    | all services have memory limits; OOM kill prevents cascading |
| T-10-07   | Tampering              | Dependency vulnerabilities | accept      | npm audit + pip audit in Plan 04; not in this plan's scope   |

</threat_model>
