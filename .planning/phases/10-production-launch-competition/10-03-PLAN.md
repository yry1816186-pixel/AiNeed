  <name>Task 1a: 生成 release keystore (人工输入密码)</name>
  <files>apps/mobile/android/app/xuno-release.keystore</files>
  <decision>
  生成 Android release 签名密钥库。此步骤不可逆 -- keystore 丢失或密码遗忘将导致无法更新已上架应用。

前置要求:

1. 设置环境变量 XUNO_KEYSTORE_PASSWORD (强密码，至少 12 位)
2. 设置环境变量 XUNO_KEY_PASSWORD (可与 store password 相同)

执行命令:

```bash
cd apps/mobile/android/app
keytool -genkeypair -v \
  -storetype PKCS12 \
  -keystore xuno-release.keystore \
  -alias xuno \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -storepass "$XUNO_KEYSTORE_PASSWORD" \
  -keypass "$XUNO_KEY_PASSWORD" \
  -dname "CN=XUNO, OU=Development, O=XUNO Team, L=Beijing, ST=Beijing, C=CN"
```

生成后立即执行备份:

1. 将 xuno-release.keystore 复制到至少 2 个安全位置 (加密网盘/U 盘)
2. 将密码记录到密码管理器 (1Password/Bitwarden 等)
3. 确保 keystore 已添加到 .gitignore (不提交到版本控制)

WARNING: 丢失 keystore = 无法发布更新。请务必备份。
</decision>

| Boundary                               | Description                                                  |
| -------------------------------------- | ------------------------------------------------------------ |
| Keystore file -> signing process       | Release key used to sign all APK updates                     |
| Metadata -> app store submission       | Store listing content represents the app publicly            |
| Keystore password -> build environment | Password injected via env vars, never hardcoded or committed |

| Threat ID | Category  | Component               | Disposition | Mitigation Plan                                                                                      |

| T-10-12   | Spoofing  | App store impersonation | accept      | Package name com.xuno.app registered per developer account; trademark pending (Phase 6)              |
