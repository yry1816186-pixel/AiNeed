2. **创建 `scripts/verify-recommendations.py`** -- 推荐效果自动化验证:

验证项:
a. **格式完整性**: 每个 seed profile 调用 `/api/v1/recommendations` 或对话接口，检查返回 JSON 包含:

- `outfits` 数组 (至少 1 套搭配)
- 每套搭配包含 `items` 数组
- 每个 item 包含 `name`, `category`, `image_url`

b. **搭配完整性**: 每套搭配的 items 应覆盖:

- 至少 1 件上装 (category 包含 "top" 或 "shirt" 或 "jacket")
- 至少 1 件下装 (category 包含 "bottom" 或 "pants" 或 "skirt")
- 至少 1 双鞋 (category 包含 "shoes")
- 至少 1 件配饰 (category 包含 "accessory")

c. **个性化差异**: 不同 profile 对同一场景推荐应有明显差异 (至少颜色/风格不同)

d. **响应时间**: 每个请求响应 < 8 秒 (per D-09)

脚本流程:

```
for each profile in seed-user-data-v2.json:
  1. POST /api/v1/auth/login (获取 token)
  2. POST /api/v1/dialog/process (发送场景请求)
  3. 验证返回格式
  4. 验证搭配完整性
  5. 记录响应时间
print summary report
```

支持 `--base-url` 参数 (默认 http://localhost:3001)
支持 `--profile` 参数 (指定单个 profile 测试)
输出格式: 表格 (profile | format_ok | outfit_complete | latency_ms)

1. **修改 `ml/services/stylist/dialog_engine.py`** -- 加强对话质量控制:

   a. 扩展 `BLOCKED_PATTERNS` 列表:

   - 添加: `re.compile(r"亲[~～]", re.IGNORECASE)` (覆盖 "亲~" 和 "亲～")
   - 添加: `re.compile(r"宝子|宝～|亲爱滴")` (更多昵称禁用)
   - 添加: `re.compile(r"系统推荐|算法分析|数据分析显示|模型为你|AI为你")` (更多 AI 暴露禁用)

   b. 增强 `filter_llm_output()`:

   - 添加 "体感延迟" 检查: 如果回复超过 200 字则截断，防止啰嗦
   - 添加 "结尾感" 检查: 如果回复不以句号/问号/感叹号结尾，添加句号
   - 添加 "连续重复" 检查: 如果连续 3 个字符重复则替换

   c. 优化 `YIYI_PERSONALITY_PROMPT`:

   - 添加: "回答控制在 100 字以内，宁可短不要长"
   - 添加: "如果用户问非穿搭问题，礼貌引导回穿搭话题"
   - 优化禁止用语列表，更精确
