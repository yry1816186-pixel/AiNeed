    Per D-01 through D-08, BRAND-01 through BRAND-06:

    **Step 1: Create Logo SVGs (3 variants)**

    Logo design direction (D-04): XUNO 字母的几何化处理融合织物曲线感。High-end fashion wordmark style (reference FARFETCH/NET-A-PORTER). NO clothes hanger imagery (user explicitly rejected it).

    `logo-horizontal.svg` — Wordmark "XUNO" in custom geometric sans-serif with textile curves. Brand terracotta #C44536 as primary color. Text flow left-to-right, viewBox ~400x100. Clean, minimal, recognizable at 32px. The "X" letterform can incorporate a subtle fabric fold/drape geometric element. The "U" can echo a collar/neckline curve. The overall feel: warm, confident, fashion-forward.

    `logo-square.svg` — Compact version for square contexts (avatar, favicon). ViewBox ~200x200. Either the "X" mark alone stylized, or XUNO stacked vertically. Same terracotta #C44536 color. Must read well at 48x48.

    `logo-monochrome.svg` — Pure black (#000000) version for dark backgrounds, pure white (#FFFFFF) for light backgrounds. Same design as horizontal but single-color fills.

    SVG creation: Write SVGs by hand using `<text>`, `<path>`, and `<rect>` elements. Use `<style>` with @font-face fallback for custom letterforms. Keep SVGs under 5KB each for fast loading.

    **Step 2: Create App Icon specifications**

    `app-icon-ios.png` — Generate a 1024x1024 PNG (or provide a generation script). Design: terracotta red (#C44536) background with white/light XUNO mark or abstract "X" symbol. Clean, bold, recognizable on a crowded home screen at 60x60.

    `app-icon-android-adaptive.json` — Android adaptive icon specification with:
    - Background: terracotta #C44536 solid
    - Foreground: white XUNO mark centered in safe zone
    - JSON config for expo/prebuild to generate all required densities

    Note: Since we cannot run image rendering tools in this environment, create an SVG-based icon and a `scripts/generate-app-icons.mjs` script that uses `sharp` or `@expo/image-utils` to convert SVG→PNG at required sizes. The script should be runnable by the user.

    **Step 3: Create Splash Lottie Animations (2 files)**

    Per D-06: 色彩晕染淡入 (color bloom fade-in). ≤1.5s duration.

    `splash-light.json` — Lottie animation:
    - Frame 0-30 (0-0.5s): Terracotta red (#C44536) circle blooms from center, expanding to fill screen
    - Frame 30-60 (0.5-1.0s): Bloom settles, opacity transitions to warm white (#FAFAF8)
    - Frame 60-90 (1.0-1.5s): XUNO wordmark fades in from center, opacity 0→1
    - Total: 90 frames at 60fps = 1.5s
    - Must be ≤500KB

    `splash-dark.json` — Same animation sequence but:
    - Background blooms to warm dark (#1A1A18) instead of warm white
    - XUNO wordmark in warm white (#F5F2ED)

    Lottie file creation: Create minimal Lottie JSON by hand using shape layers. The animation uses only:
    - Ellipse shape layer for the bloom circle
    - Fill color with opacity keyframes
    - Text layer or path layer for XUNO wordmark (use pre-composed path for reliability)
    - Keep total layers ≤5, no precomps, no images

    If hand-crafting Lottie JSON is impractical, create a detailed animation spec document (`splash-animation-spec.md`) with exact keyframe values, colors, and timing. User can then create in After Effects and export.

    **Step 4: Write Brand Guidelines Document**

    Create `apps/mobile/docs/brand-guidelines.md` covering (BRAND-04):

    1. **Brand Overview** — XUNO identity, positioning, personality (warm, opinionated friend per decision #1)
    2. **Logo** — 3 variants with usage rules, minimum sizes, clear space, do's/don'ts
    3. **Color Palette** —
       - Primary: Terracotta Red #C44536 (text use: TerracottaDark #A86548 for AA compliance, D-02)
       - Secondary: Sage #8B9A7D, Camel #B5A08C, Slate #7B8FA2
       - Neutral: Full scale from white to black
       - Semantic: Status colors (success/warning/error/info)
       - Dark Mode: Warm gray base + coral accent
       - Color usage rules: which contexts use which colors
    4. **Typography Scale** — Font families, size scale, weight usage (heading/body/caption/overline)
    5. **Spacing System** — 4px grid, spacing scale, component spacing defaults
    6. **Icon Style** — Phosphor icon set customization direction (D-08): stroke weight, corner radius, size norms
    7. **Illustration Style** — Warm, fashion-forward, body-positive (decision #36)
    8. **Decorative Patterns** — Brand motifs for backgrounds, cards, dividers (D-08)
    9. **Photography Direction** — Style guidelines for user-facing imagery
    10. **Accessibility** — Contrast requirements, touch targets, accessible naming conventions
