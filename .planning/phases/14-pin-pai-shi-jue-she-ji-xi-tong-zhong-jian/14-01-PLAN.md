    `shadows.yaml` — 5 elevation levels (none/sm/md/lg/xl) with offset/radius/opacity

    `motion.yaml` — Duration (instant:50/fast:150/normal:300/slow:500/lingering:800), easing curves (easeOut/quintOut/circOut), spring configs (gentle/bouncy/snappy)

    **Step 3: Create semantic YAML tokens (6 files)**

    Create `apps/mobile/tokens/semantics/` directory. Each semantic color token MUST have both `light:` and `dark:` variants.

    `colors.yaml` — Functional semantic names per D-12:
    - `surface.primary/secondary/tertiary/elevated/overlay` — light: white/warm whites, dark: warm grays (#1A1A18/#161412/#201E1C per D-20)
    - `text.primary/secondary/tertiary/inverse/brand/link` — light: dark neutrals, dark: warm lights (#F5F2ED/#B8B0A8 per WCAG audit)
    - `interactive.primary/secondary/hover/pressed/disabled` — light: terracotta #C44536, dark: coral #FF7F7F (D-21)
    - `status.success/warning/error/info` — both modes, all AA compliant
    - `border.light/default/strong/brand`
    - `background.modal/card/sheet/input`

    `spacing.yaml` — Component spacing defaults: button padding, card padding, input padding, list gap, screen margin

    `typography.yaml` — Heading (h1-h6), body (large/default/small), caption, overline, label styles referencing primitive sizes/weights

    `radius.yaml` — Component radius defaults: button/card/input/avatar/badge/sheet/modal

    `shadows.yaml` — Semantic elevation: card/modal/dropdown/tooltip/notification

    `motion.yaml` — Transition presets: fast/medium/slow duration, entrance/exit patterns, spring configs for different interactions

    **Step 4: Create component YAML tokens (7 files)**

    Create `apps/mobile/tokens/components/` with one file per component type:
    button.yaml, card.yaml, input.yaml, avatar.yaml, badge.yaml, bottom-sheet.yaml, toast.yaml

    Each references semantic tokens: e.g., `button.primary.background: "{semantics.colors.interactive.primary}"`

    **Step 5: Create Style Dictionary config + build script**

    `apps/mobile/config.json` — Style Dictionary configuration:
    - source: `['tokens/**/*.yaml']`
    - Register YAML parser (from yaml npm package)
    - Platform `ts` with custom format for TypeScript ES module output
    - Three output files: `primitive-tokens.ts`, `semantic-tokens.ts`, `component-tokens.ts`
    - Transform group: custom `tsRN` (React Native) that strips `px` units and outputs plain numbers

    `apps/mobile/scripts/build-tokens.mjs` — Node.js script:
    - Import Style Dictionary and yaml
    - Register YAML parser
    - Register custom TypeScript format that exports typed objects (not `any`)
    - Register custom transform for React Native (strip px, output number)
    - Run build with config.json
    - Output to `src/design-system/theme/tokens/generated/`
    - Also generate `index.ts` barrel export
