# Plan 06-06: Security Hardening - Nginx+TLS+Port+API Keys+Proxy

<objective>
Complete security hardening: add Nginx reverse proxy with TLS to docker-compose, bind all service ports to 127.0.0.1, migrate API keys to Docker Secrets/Vault, implement server-side proxy for mobile API requests.
</objective>

<must_haves>

- Nginx reverse proxy with Let's Encrypt TLS in docker-compose
- All service ports bound to 127.0.0.1 (not 0.0.0.0)
- API keys migrated from environment variables to Docker Secrets
- Server-side proxy replaces EXPO_PUBLIC_API_URL direct access
- EXPO_PUBLIC_API_KEY and EXPO_PUBLIC_OPENAI_KEY removed from mobile
  </must_haves>

<tasks>

<task id="06-06-01">
<read_first>
- docker-compose.yml
- k8s/ingress.yml
</read_first>
<objective>Add Nginx reverse proxy with TLS to docker-compose</objective>
<action>
1. Create `infrastructure/nginx/nginx.conf`:
   ```nginx
   upstream backend {
     server backend:3001;
   }
   upstream ai_service {
     server ai-stylist:8002;
   }
   upstream minio_api {
     server minio:9000;
   }

server {
listen 80;
server*name *;
return 301 https://$host$request_uri;
}

server {
listen 443 ssl http2;
server*name *;

     ssl_certificate /etc/letsencrypt/live/xuno.ai/fullchain.pem;
     ssl_certificate_key /etc/letsencrypt/live/xuno.ai/privkey.pem;
     ssl_protocols TLSv1.2 TLSv1.3;
     ssl_ciphers HIGH:!aNULL:!MD5;
     ssl_prefer_server_ciphers on;

     # Security headers
     add_header X-Frame-Options DENY;
     add_header X-Content-Type-Options nosniff;
     add_header X-XSS-Protection "1; mode=block";
     add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;

     # API proxy
     location /api/ {
       proxy_pass http://backend;
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto $scheme;
     }

     # AI service proxy
     location /ai/ {
       proxy_pass http://ai_service/;
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
     }

     # MinIO proxy
     location /storage/ {
       proxy_pass http://minio_api/;
       proxy_set_header Host $host;
     }

     # Health check
     location /health {
       proxy_pass http://backend/health;
     }

}

````

2. Create `infrastructure/nginx/ssl-setup.sh`:
- Script to obtain Let's Encrypt certificates using certbot
- Supports standalone and webroot modes
- Auto-renewal cron setup

3. In `docker-compose.yml`, add Nginx service:
```yaml
nginx:
  image: nginx:1.25-alpine
  container_name: xuno-nginx
  ports:
    - "80:80"
    - "443:443"
  volumes:
    - ./infrastructure/nginx/nginx.conf:/etc/nginx/conf.d/default.conf:ro
    - ./infrastructure/nginx/certs:/etc/letsencrypt:ro
  depends_on:
    - backend
  networks:
    - xuno-network
  restart: unless-stopped
````

</action>

- `infrastructure/nginx/nginx.conf` contains `ssl_protocols TLSv1.2 TLSv1.3` (grep: `TLSv1.2 TLSv1.3`)
- `infrastructure/nginx/nginx.conf` contains `X-Frame-Options DENY` (grep: `X-Frame-Options DENY`)

</task>

     secrets:
       - fal_api_key

       - jwt_secret
       - database_url

       - FAL_KEY_FILE=/run/secrets/fal_api_key
