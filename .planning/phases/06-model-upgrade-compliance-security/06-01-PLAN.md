# Plan 06-01: FashionSigLIP Hard Replace + Qdrant Rebuild

<objective>
Hard replace FashionCLIP with FashionSigLIP across the entire ML pipeline. Update vector dimensions from 512 to 1152, rebuild Qdrant collection, and create batch embedding pipeline.
</objective>

<must_haves>

- All embedding operations use FashionSigLIP (1152-dim), zero references to FashionCLIP/CLIPModel
- Qdrant collection rebuilt with 1152-dim vectors
- Batch embedding pipeline for re-encoding all products
- seed_qdrant.py works with new model
  </must_haves>

<tasks>

<task id="06-01-01">
<read_first>
- ml/services/rag/embeddings.py
- ml/requirements.txt
</read_first>
<objective>Replace FashionCLIP with FashionSigLIP in embeddings.py</objective>
<action>
1. In `ml/requirements.txt`, add line: `peft>=0.10.0`
2. In `embeddings.py`:
   - Change import from `from transformers import CLIPModel, CLIPProcessor` to `from transformers import SiglipModel, SiglipProcessor`
   - Change `_DEFAULT_MODEL = "patrickjohncyh/fashion-clip"` to `_DEFAULT_MODEL = "marqo/fashionSigLIP"`
   - In `EmbeddingConfig` class, change `dimension: int = 512` to `dimension: int = 1152`
   - In `EmbeddingService.__init__()`, change `self.model = CLIPModel.from_pretrained(...)` to `self.model = SiglipModel.from_pretrained(...)`
   - Change `self.processor = CLIPProcessor.from_pretrained(...)` to `self.processor = SiglipProcessor.from_pretrained(...)`
   - In `encode_image()`, replace `inputs = self.processor(images=image, return_tensors="pt")` with `inputs = self.processor(images=image, return_tensors="pt").to(self.device)` and replace `outputs = self.model.get_image_features(**inputs)` with `outputs = self.model.vision_model(**inputs)` then `embedding = outputs.last_hidden_state[:, 0, :]` (use CLS token)
   - In `encode_query()`, replace `inputs = self.processor(text=query, return_tensors="pt")` with `inputs = self.processor(text=query, return_tensors="pt").to(self.device)` and replace `outputs = self.model.get_text_features(**inputs)` with `outputs = self.model.text_model(**inputs)` then `embedding = outputs.last_hidden_state[:, 0, :]`
   - Add L2 normalization after both encode methods: `embedding = embedding / embedding.norm(dim=-1, keepdim=True)`
   - Remove all references to `CLIPModel`, `CLIPProcessor`, `compute_clip_loss`
</action>
<acceptance_criteria>
- `embeddings.py` contains `SiglipModel` and `SiglipProcessor` (grep: `SiglipModel`)
- `embeddings.py` does NOT contain `CLIPModel` or `CLIPProcessor` (grep returns empty)
- `EmbeddingConfig.dimension` equals 1152 (grep: `dimension: int = 1152`)
- `_DEFAULT_MODEL` equals `"marqo/fashionSigLIP"` (grep: `marqo/fashionSigLIP`)
- `requirements.txt` contains `peft>=0.10.0`
</acceptance_criteria>
</task>
