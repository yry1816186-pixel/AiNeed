<objective>Implement product sync service with deduplication and embedding</objective>
<action>
1. In `product-sync.service.ts`:
   - Add method `async syncFull(): Promise<SyncResult>` that:
     a. Fetches all products from Taobao and JD
     b. Deduplicates by `sourceId + source` combination
     c. Upserts to database via Prisma
     d. Triggers FashionSigLIP embedding for new/updated products
     e. Returns `{ added: number, updated: number, skipped: number, embedded: number }`
   - Add method `async syncIncremental(since: Date): Promise<SyncResult>` that:
     a. Fetches only products modified since `since` date
     b. Same dedup + upsert + embed flow
   - Add method `async syncHotItems(): Promise<SyncResult>` that:
     a. Fetches trending/hot items from both sources
     b. Prioritizes embedding for hot items
   - Add deduplication logic: hash of `title + brand + category` as dedup key
   - Add embedding trigger: after upsert, call `qdrantService.upsertBatch()` with new embeddings
</action>
<acceptance_criteria>
- `product-sync.service.ts` contains `syncFull` method (grep: `async syncFull`)
- `product-sync.service.ts` contains `syncIncremental` method (grep: `async syncIncremental`)

- File contains deduplication logic (grep: `dedup\|sourceId.*source\|title.*brand.*category`)
</acceptance_criteria>

<objective>Implement scheduled sync with BullMQ</objective>
<action>
1. In `sync-scheduler.service.ts`:
   - Add daily full sync job: cron `0 3 * * *` (3 AM daily) → calls `productSync.syncFull()`
   - Add hourly incremental sync: cron `0 * * * *` → calls `productSync.syncIncremental(lastSyncTime)`
   - Add hot item refresh: cron `*/15 * * * *` (every 15 min) → calls `productSync.syncHotItems()`
   - Use BullMQ queue with `SYNC_QUEUE` name
   - Add job failure handling: retry 3 times with 5-minute backoff
   - Add job success logging: `logger.log("Full sync completed: {result}")`
</action>
