         labels = torch.arange(logits.shape[0], device=logits.device)
         loss = F.cross_entropy(logits, labels)

<objective>Build 5M params preference model v1 with dual-tower architecture</objective>
<action>
1. Create `ml/services/recommender/preference_model.py`:
   - Define `UserTower` module:
     ```python
     class UserTower(nn.Module):
         # Input: bodyType(1) + styleExpression(1) + budget(1) + scenario(1) = 4 categorical features
         # Embedding: 4 features * 32 dim each = 128 dim
         # FC: 128 -> 128 -> 128 (with ReLU + BatchNorm)
         # Output: 128-dim user embedding
     ```
   - Define `ItemTower` module:
     ```python
     class ItemTower(nn.Module):
         # Input: FashionSigLIP embedding (1152 dim) + category(1) + price(1) = 1154 features
         # FC: 1154 -> 512 -> 256 -> 128 (with ReLU + BatchNorm)
         # Output: 128-dim item embedding
     ```
   - Define `PreferenceModel` module:
     ```python
     class PreferenceModel(nn.Module):
         # user_tower: UserTower
         # item_tower: ItemTower
         # cross_layer: Linear(256, 128) -> ReLU -> Linear(128, 1)
         # forward: concat user_emb, item_emb -> cross_layer -> sigmoid -> preference score
     ```
   - Total params: ~5M (UserTower ~1M + ItemTower ~2.5M + CrossLayer ~0.5M + Embeddings ~1M)
   - Training: BPR loss with negative sampling
   - Add FastAPI endpoints: `/preference/predict`, `/preference/train`, `/preference/status`
   - Add `--save` and `--load` for model persistence

2. In `preference-learning.service.ts`:
   - Add method `async getPreferenceScore(userId: string, itemId: string): Promise<number>` that calls Python `/preference/predict`
   - Add fallback: if Python service unavailable, use existing weight-based scoring
     </action>
