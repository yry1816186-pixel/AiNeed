# Plan 05-02: Visual Consistency

<objective>
Replace all hardcoded colors with DesignTokens references across the mobile app. Implement unified three-state (Loading/Empty/Error) coverage on all core screens. Update ShimmerSkeleton to use brand-aware warm camel colors instead of neutral gray.
</objective>

<threat_model>
**Assets:** None specific to this plan (visual changes only)
**Threats:** Color changes may reduce contrast ratios, affecting accessibility for visually impaired users. ShimmerSkeleton color change from neutral gray (#F0E8E4) to warm camel at 20% opacity (rgba(196,149,106,0.2)) may have insufficient contrast on light backgrounds.
**Mitigations:**

- After all color replacements, verify WCAG 2.1 AA contrast ratios (4.5:1 for text, 3:1 for UI components)
- ShimmerSkeleton is a decorative loading indicator, not informational text — lower contrast acceptable
- All text color replacements maintain or improve existing contrast
  **HIGH severity blockers:** None
  </threat_model>
