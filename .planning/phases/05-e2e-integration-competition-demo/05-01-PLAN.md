# Plan 05-01: E2E Data Wiring

<objective>
Wire TodayScreen and DiscoverScreen to real backend APIs, eliminating all hardcoded data. Add breakdown fields to Orchestrator output for funnel visualization. Frontend consumes RecommendationOutput structure directly.
</objective>

<threat_model>
**Assets:** Weather API keys (QWeather), user location data, recommendation API responses
**Threats:** API key exposure in mobile client, unauthorized API access, data leakage through error messages
**Mitigations:**

- Weather API calls go through backend proxy (GET /weather), never direct from mobile with API keys
- Recommendation API requires auth token (existing JWT middleware)
- Error responses do not expose internal stack traces or API details
  **HIGH severity blockers:** None — weather API key stays server-side only
  </threat_model>
