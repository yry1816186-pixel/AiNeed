### RecommendationFunnel

6-layer funnel visualization showing recommendation pipeline:

| Layer | Label    | Color                       | Data Source            |
| ----- | -------- | --------------------------- | ---------------------- |
| L1    | 全部候选 | #E8DDD5 (warmGray200)       | totalCandidates        |
| L2    | 场景筛选 | #D4C4B5 (warmGray300)       | afterSceneFilter       |
| L3    | 尺码筛选 | #C0AA95 (warmGray400)       | afterSizeFilter        |
| L4    | 预算筛选 | #AB9075 (warmGray500)       | afterBudgetFilter      |
| L5    | 风格筛选 | #977655 (warmGray600)       | afterStyleFilter (new) |
| L6    | 最终推荐 | #C67B5C (terracotta accent) | finalCount             |

Visual spec:

- Horizontal bar chart, bars stacked vertically
- Each bar: full-width with rounded corners (borderRadius: 8px)
- Bar height: 36px
- Gap between bars: 4px (xs)
- Labels: Label typography (14px/regular), left-aligned inside bar
- Count badge: right-aligned, Label (14px/regular), terracotta for L6
- Animation: bars animate width from 0% to target% with spring(0.7, 18)
- L6 bar has terracotta background with white text
- Container padding: md (16px) all sides
- Background: warmWhite (#FAFAF8) with 1px warmGray200 border

Interaction:

- Tap any bar → show tooltip with count and percentage of L1
- L6 bar pulse animation (scale 1.0→1.02→1.0, 2s loop) to draw attention

### ProfileDebugPanel

Demo-only profile modifier for competition:

Visual spec:

- Position: bottom sheet, snapPoints: ["60%"]
- Header: "演示配置" in Heading (20px/semibold), with close button
- Body: scrollable form with sections
- Each field: Label (14px/regular) + value display + edit button
- Fields: bodyType, styleExpression, primaryScenarios (multi-select)
- Save button: terracotta gradient, full-width, "应用配置" CTA
- Danger zone: "重置为默认" with destructive color, confirmation required
- Background: warmWhite, cards: warmGray50
- Only visible in **DEV** mode or when demo flag is active

## Phase 5 — Competition Demo Path

Demo flow visual contract:

1. **Today Tab**: WeatherSceneCard shows "明天 12°C 面试推荐 3 套"

   - Temperature: Display (28px/semibold), terracotta
   - Scene label: Heading (20px/semibold), charcoal
   - Count badge: Label (14px/regular), terracotta background, white text

2. **User taps → Stylist**: AiStylistUnifiedScreen opens with pre-filled context

   - System message: "明天 12°C，我为你准备了 3 套面试穿搭"
   - TypewriterMessage with typewriter animation

3. **User says "不喜欢正式的"**: AI adjusts

   - New TypewriterMessage: "了解！我帮你换成更轻松的风格"
   - StudioRecommendCard updates with new outfits

4. **RecommendationFunnel**: Shows 6-layer pipeline

   - Animated bar chart as specified above
   - L6 bar pulses to highlight final count

5. **Different profiles → different results**:
   - ProfileDebugPanel allows switching bodyType/styleExpression
   - After applying, recommendations re-fetch and funnel re-animates
