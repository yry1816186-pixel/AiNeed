# Plan 15-02: SmartImage + Splash Lottie + 动效预设验证

## Objective

Create SmartImage progressive loading component using expo-image with blurhash + CDN URL optimization. Integrate Splash Lottie animation into app startup with ≤1.5s playback and light/dark variants. Verify animation preset system completeness.

- @15-CONTEXT.md — SmartImage and Splash decisions

## Tasks

### Task 1: Create SmartImage component

**type:** auto

Create `design-system/components/SmartImage/SmartImage.tsx` wrapping expo-image.

Features:

- `expo-image` as base with `contentFit="cover"` default
- `blurhash` prop: string from backend, rendered as placeholder
- Auto CDN URL params: append `?w={width}&q=80&format=webp` to source URI
- Progressive loading: blurhash → low-res → full-res (expo-image built-in)
- Memory + disk cache enabled
- `onLoad` / `onError` callbacks
- accessibilityLabel prop
- Dark mode: slightly reduced brightness for dark theme
- Re-animated fade-in transition on load complete

Props interface:

```typescript
interface SmartImageProps {
  uri: string;
  blurhash?: string;
  width?: number;
  height?: number;
  aspectRatio?: number;
  borderRadius?: number;
  onLoad?: () => void;
  onError?: (error: Error) => void;
  accessibilityLabel?: string;
  style?: ViewStyle;
}
```

Write render tests.

**Done when:** SmartImage renders with blurhash placeholder, auto-appends CDN params, fade-in animation works.
