# Plan 15-01: 组件目录重构 + Semantic Token 迁移

## Objective

Merge `design-system/primitives/` and `design-system/ui/` into a single `design-system/components/` directory with barrel exports. Migrate all 8 atomic components to use Phase 14 semantic/component tokens exclusively — zero hardcoded color/spacing/font-size values.

## Context

- @15-CONTEXT.md — decisions and codebase context
- @apps/mobile/src/design-system/theme/tokens/generated/semantic-tokens.ts — Phase 14 semantic tokens
- @apps/mobile/src/design-system/theme/tokens/generated/component-tokens.ts — Phase 14 component tokens
- @apps/mobile/src/design-system/theme/tokens/legacy-map.ts — legacy bridge (to be removed)

## Threat Model

| Asset                    | Threat                                 | Disposition                                       |
| ------------------------ | -------------------------------------- | ------------------------------------------------- |
| Component barrel exports | Import breakage across feature screens | mitigate — maintain re-export compatibility layer |

### Task 2: Migrate Button to semantic tokens

**type:** auto

Move `primitives/Button/Button.tsx` to `components/Button/Button.tsx`. Replace all `Colors.xxx`, `Spacing.xxx`, `BorderRadius.xxx` direct references with semantic token imports from `tokens/generated/semantic-tokens.ts` and `tokens/generated/component-tokens.ts`.

Key changes:

- `Colors.primary[500]` → semantic `tokens.interactive.primary`
- `Colors.neutral[100]` → semantic `tokens.surface.secondary`
- `Colors.white` → semantic `tokens.text.inverse`
- `Colors.error[500]` → semantic `tokens.interactive.danger`
- `BorderRadius.lg/xl/2xl` → component tokens `tokens.component.button.borderRadius`
- `DesignTokens.typography.sizes.*` → semantic typography scale
- Ensure dark mode works via themeStore subscription

Write snapshot test in `__tests__/Button.test.tsx` verifying:

- Renders all 6 variants
- Renders all 4 sizes
- Loading state shows ActivityIndicator
- Disabled state has opacity 0.5
- accessibilityLabel prop forwarded

**Done when:** Button uses zero hardcoded color/spacing values, passes render tests, barrel export works.

### Task 3: Migrate Card to semantic tokens

**type:** auto

Move `primitives/Card/Card.tsx` to `components/Card/Card.tsx`. Apply same token migration pattern. Remove ProductCard (it belongs in feature-specific code, not atomic component library).

Key changes:

- All `Colors.xxx` → semantic tokens
- `Shadows.md` → semantic elevation tokens
- `BlurView` glass variant → semantic glass tokens
- Card press animation stays (already using SpringConfigs)

Write render tests verifying 5 variants render correctly.

**Done when:** Card uses semantic tokens exclusively, tests pass.

### Task 4: Migrate remaining 4 components (Input, Avatar, Badge, Toast)

**type:** auto

- `primitives/Input/Input.tsx` → `components/Input/Input.tsx`
- `ui/Avatar.tsx` → `components/Avatar/Avatar.tsx`
- `ui/Badge.tsx` → `components/Badge/Badge.tsx`
- `primitives/Toast/Toast.tsx` → `components/Toast/Toast.tsx` + `ToastProvider.tsx`

Apply semantic token migration to each. Write render tests.

**Done when:** All 4 components migrated, semantic tokens only, tests pass.

### Task 5: Migrate Skeleton + BottomSheet + create compatibility layer

**type:** auto

Move Skeleton from `skeleton/Skeleton.tsx` and `skeleton/AdvancedSkeleton.tsx` to `components/Skeleton/Skeleton.tsx` (merge into single component with variants). Move BottomSheet from `ui/BottomSheets.tsx` to `components/BottomSheet/BottomSheet.tsx`.

Create compatibility re-exports at old paths:

- `primitives/index.ts` → re-export from `components/`
- `ui/index.ts` → re-export from `components/`
- `skeleton/index.ts` → re-export from `components/Skeleton/`

This prevents import breakage across all feature screens.

**Done when:** All 8 atomic components in `components/`, old paths re-export correctly, `tsc --noEmit` passes.
