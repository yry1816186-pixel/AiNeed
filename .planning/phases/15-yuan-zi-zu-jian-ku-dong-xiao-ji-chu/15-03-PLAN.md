# Plan 15-03: 暗色模式验证 + 组件测试全覆盖

## Objective

Full dark mode rendering verification across all 8 atomic components. Complete test coverage for all component variants. Final verification that all Phase 15 success criteria pass.

## Context

- @15-01-PLAN.md — component migration plan
- @15-02-PLAN.md — SmartImage and Splash plan
- @apps/mobile/src/design-system/theme/themeStore.ts — dark mode toggle

## Tasks

### Task 1: Dark mode render verification for all 8 components

**type:** auto

For each of the 8 atomic components, verify:

1. Component renders correctly in light mode
2. Component renders correctly in dark mode
3. No hardcoded colors that break in dark mode
4. WCAG AA contrast ratios maintained (text on backgrounds)

Write a dark mode test suite that:

- Sets themeStore to light, renders component, snapshots
- Sets themeStore to dark, renders component, snapshots
- Compares both render without errors

Components to verify:

- Button (6 variants × 4 sizes × 2 themes)
- Card (5 variants × 2 themes)
- Input (types, error state × 2 themes)
- Avatar (5 sizes × 2 themes)
- Badge (variants × 2 themes)
- Skeleton (variants × 2 themes)
- BottomSheet (open/closed × 2 themes)
- Toast (4 variants × 2 themes)

**Done when:** All components render correctly in both themes, no visual regressions.

### Task 2: Full component test suite

**type:** auto

Write comprehensive tests for each component covering:

- All variants render without crashing
- All size variants render
- Loading/disabled states work
- onPress handlers fire correctly
- accessibilityLabel forwarded
- Icon rendering (for Button, Input)
- Auto-dismiss (for Toast)
- Snap points (for BottomSheet)

**Done when:** All tests pass, coverage >80% for each component.

### Task 3: Final success criteria verification

**type:** auto

Verify all Phase 15 success criteria:

1. ✅ 8 原子组件在亮色/暗色模式下正确渲染
2. ✅ 所有组件使用 Design Token 引用，零硬编码颜色/字号/间距
3. ✅ Skeleton shimmer 动画使用 Reanimated（无额外原生依赖）
4. ✅ SmartImage 支持 blurhash + 渐进式加载 + 缓存 + CDN URL
5. ✅ animationPresets 集中定义所有 easing/duration/spring 配置
6. ✅ Splash Lottie ≤1.5s，亮/暗变体

Write VERIFICATION.md with results.

**Done when:** All 6 success criteria verified and documented.
