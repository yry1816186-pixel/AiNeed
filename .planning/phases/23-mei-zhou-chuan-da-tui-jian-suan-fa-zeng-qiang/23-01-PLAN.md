**Part A — Add `score_outfit_candidates()` method to FullOutfitEngine class (ml/services/stylist/full_outfit_engine.py):**

Insert a new public method after `generate_outfit_plan()` (around line 640) but before the private methods. Use this EXACT signature:

```python
def score_outfit_candidates(
    self,
    candidates: List[List[Dict[str, Any]]],
    user_profile: UserProfile,
    context: OutfitContext,
    budget: float = 5000.0,
) -> List[Dict[str, Any]]:
```

Where `candidates` is a list of outfits, each outfit is a list of item dicts. Each item dict has keys: `item_id`, `name`, `category`, `color_primary`, `style_tags`, `price`, `seasons`, `occasions`, `material`, `brand`.

Implementation:

1. For each candidate outfit (list of item dicts), convert dicts to ClothingItem dataclass instances
2. Assign items to a FullOutfitPlan (`plan_id = f"ranked_{uuid.uuid4().hex[:12]}"`)
3. Map items to plan slots: category "outerwear"→plan.outer_top, "tops"→plan.inner_top, "bottoms"→plan.bottom, "footwear"→plan.shoes, everything else→plan.accessories
4. Call `self._score_outfit(items, user_profile, context)` for overall_score
5. Call individual scoring methods and store per-dimension scores:
   - `self._check_color_harmony(items).score` → color_harmony_score
   - `self._check_style_consistency(items).score` → style_consistency_score
   - `self._check_body_fit(items, user_profile).score` → body_fit_score
   - Weather: if context.temperature_celsius exists → `self._check_weather_suitability(items, context.temperature_celsius).score` else → `self._estimate_season_score(items, context.season or "")`
   - Budget: use `self._check_budget(items, budget).score` if that method exists, otherwise default to 70.0
6. Add `provider = "full_outfit_engine"` to each result
7. Return list of dicts (use `plan.to_dict()` if FullOutfitPlan has it, otherwise construct explicit dict with keys: `plan_id, overall_score, color_harmony_score, style_consistency_score, body_fit_score, weather_score, occasion, season, provider`)
8. Sort by overall_score descending before returning
9. Handle case where candidates is empty: return empty list

```python
@router.post("/score-outfits", response_model=ScoreOutfitResponse)
async def score_outfits(request: ScoreOutfitRequest) -> Dict[str, Any]:
    """同步精排候选搭配方案

    接收 NestJS 粗排结果，调用 FullOutfitEngine 进行 6 维精排评分。
    同步端点——不适用 task/poll 模式。
    """
    if not _service_available:
        raise ModelNotLoadedError(model_name="intelligent_stylist")

    try:
        engine = get_outfit_engine()
        user_profile = _to_user_profile(request.user_profile)
        context = OutfitContext(
            occasion=request.scene_context.occasion or "daily",
            temperature_celsius=None,
            season=request.scene_context.season or "",
        )

        # Convert Pydantic candidates to dict format for engine
        candidates = [
            [item.model_dump() for item in outfit]
            for outfit in request.candidates
        ]

        ranked = engine.score_outfit_candidates(
            candidates=candidates,
            user_profile=user_profile,
            context=context,
            budget=request.budget,
        )

        logger.info(
            "score-outfits completed",
            extra={"service": "stylist", "endpoint": "score-outfits", "candidates_in": len(candidates), "ranked_out": len(ranked)},
        )

        return {
            "success": True,
            "ranked_outfits": ranked,
            "provider": "full_outfit_engine",
        }
    except (ModelNotLoadedError, InferenceError, ValidationError):
        raise
    except Exception as e:
        logger.error("score-outfits failed", extra={"service": "stylist", "endpoint": "score-outfits", "error": str(e)})
        raise InferenceError(message=f"精排失败: {str(e)}")
```
