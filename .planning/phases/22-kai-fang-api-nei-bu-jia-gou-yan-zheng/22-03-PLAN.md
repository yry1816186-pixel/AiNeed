    **2. `scripts/seed-partner-key.ts`** — Test key generation script:
    Create a standalone TypeScript script that:
    - Imports `PrismaClient` from `@prisma/client` and `crypto` from node
    - Function `generatePartnerApiKey(name: string, rateLimit: number = 60)`:
      1. Generate a random 32-byte key: `crypto.randomBytes(32).toString('hex')` → this is the full API key (64 hex chars)
      2. Compute `keyPrefix`: first 8 chars of the full key
      3. Compute `keyHash`: `crypto.createHash('sha256').update(fullKey).digest('hex')`
      4. Insert into PartnerApiKey table via Prisma
      5. Return the full key (for one-time display)
    - Main function:
      1. Create PrismaClient instance
      2. Call `generatePartnerApiKey('test-partner-key', 60)`
      3. Print to console:
         ```
         =========================================
         Partner API Key Created (SAVE THIS - shown once)
         =========================================
         Name: test-partner-key
         Full Key: <the-full-key>
         Key Prefix: <first-8-chars>
         Rate Limit: 60 req/min
         =========================================
         ```
      4. Disconnect Prisma
    - Script should be runnable via: `npx ts-node apps/backend/src/domains/platform/partner-api/scripts/seed-partner-key.ts`
      or add a pnpm script `"seed:partner-key"` in apps/backend/package.json
