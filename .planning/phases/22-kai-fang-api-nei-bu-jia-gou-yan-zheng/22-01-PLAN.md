    Create the partner-api domain module with these files:

    **1. `types/partner-api.types.ts`**:
    Define:
    - `PartnerApiRequest` interface: `{ keyPrefix: string; timestamp: number; signature: string; body: string; method: string; path: string; ip?: string }`
    - `PartnerApiKeyData` interface matching the Prisma model fields (id, name, keyPrefix, rateLimit, status, permissions, expiresAt)
    - `PARTNER_API_HEADERS` constant: `{ API_KEY: 'X-Api-Key', TIMESTAMP: 'X-Timestamp', SIGNATURE: 'X-Signature' }`

    **2. `guards/partner-api-key.guard.ts`** — `PartnerApiKeyGuard`:
    - Implements `CanActivate`
    - Injects `PrismaService`
    - `canActivate()`:
      1. Extract `X-Api-Key` header from request → this is the keyPrefix (first 8 chars of the full key)
      2. Query `partnerApiKey.findFirst({ where: { keyPrefix } })`
      3. If not found → throw `UnauthorizedException('Invalid API key')`
      4. If `status !== 'active'` → throw `UnauthorizedException('API key is not active')`
      5. If `expiresAt` is set and `expiresAt < new Date()` → throw `UnauthorizedException('API key has expired')`
      6. Attach the full key record to `request['partnerApiKey']` for downstream use
      7. Return true
    - Use `@Injectable()` decorator

    **3. `guards/partner-auth.guard.ts`** — `PartnerAuthGuard`:
    - Implements `CanActivate`
    - Injects `PrismaService`
    - `canActivate()`:
      1. Extract headers: `X-Api-Key` (full API key for HMAC), `X-Timestamp`, `X-Signature`
      2. Validate timestamp: `|Date.now() - timestamp| <= 5 * 60 * 1000` (5 min window). If exceeded → throw `UnauthorizedException('Request timestamp expired')`
      3. Derive keyPrefix from the first 8 chars of `X-Api-Key` header value
      4. Query `partnerApiKey.findFirst({ where: { keyPrefix } })`
      5. Verify key exists and is active (same checks as PartnerApiKeyGuard)
      6. Compute expected signature: `crypto.createHmac('sha256', fullApiKey).update(timestamp + method + path + body).digest('hex')`
         - timestamp = `X-Timestamp` header value as string
         - method = request.method (GET/POST)
         - path = request.url (the path portion)
         - body = raw body string (use `request.body` serialized as JSON, or raw body if available)
      7. Compare `expectedSignature === providedSignature`. If mismatch → throw `UnauthorizedException('Invalid signature')`
      8. Attach key record to `request['partnerApiKey']`
      9. Return true
    - Import `crypto` from Node.js for HMAC
    - Use `@Injectable()` decorator

    **4. `partner-api.module.ts`**:
    - `@Module({})` with:
      - imports: `PrismaModule` (from `common/prisma/prisma.module`)
      - providers: [PartnerApiKeyGuard, PartnerAuthGuard]
      - exports: [PartnerApiKeyGuard, PartnerAuthGuard]
    - Register as a standalone module (controller will be added in Plan 02)

    After creating files, register `PartnerApiModule` in `apps/backend/src/app.module.ts`:

    - Add to the `imports` array of `AppModule`

| Threat ID | Category            | Component                | Disposition | Mitigation Plan                                                                   |
| --------- | ------------------- | ------------------------ | ----------- | --------------------------------------------------------------------------------- |
| T-22-01   | S (Spoofing)        | partner-auth.guard.ts    | mitigate    | HMAC-SHA256 signature verification with shared secret key                         |
