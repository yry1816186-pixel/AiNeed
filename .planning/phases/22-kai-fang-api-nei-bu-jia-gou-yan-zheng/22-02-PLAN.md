  <action>
    **1. `guards/partner-rate-limit.guard.ts`** — `PartnerRateLimitGuard`:
    - Implements `CanActivate`
    - Injects `RedisService` (use `@Inject(REDIS_CLIENT)` to get raw Redis client, or use `redisService.getClient()`)
    - `canActivate(context: ExecutionContext)`:
      1. Get `request['partnerApiKey']` (set by PartnerAuthGuard from Plan 01)
      2. If no key data → throw `UnauthorizedException('API key not found')`
      3. Get `rateLimit` from key data (default 60)
      4. Build Redis key: `xuno:partner:ratelimit:${keyData.id}`
      5. Get current timestamp in milliseconds: `Date.now()`
      6. Define window: 60 seconds (60000 ms)
      7. Execute Redis pipeline:
         - `ZREMRANGEBYSCORE key 0 (now - 60000)` — remove entries older than 1 min
         - `ZADD key now now` — add current request with score=timestamp, value=timestamp (unique enough)
         - `ZCARD key` — count entries in window
         - `EXPIRE key 120` — TTL 2 minutes for cleanup
      8. If count > rateLimit:
         - Set `Retry-After` header on response: `Math.ceil(60)` seconds
         - Throw `HttpException('Rate limit exceeded', 429)` with `{ headers: { 'Retry-After': '60' } }`
      9. Return true

    **2. `services/partner-api-log.service.ts`** — `PartnerApiLogService`:
    - `@Injectable()`
    - Inject `PrismaService`
    - `async logCall(data: { keyId: string; endpoint: string; statusCode: number; responseTime: number; ip?: string })`:
      - Insert into `partnerApiCallLog` table via `this.prisma.partnerApiCallLog.create({ data })`
    - Use `Date.now()` diff to calculate responseTime (caller should pass startTime, or service calculates)

  </action>
