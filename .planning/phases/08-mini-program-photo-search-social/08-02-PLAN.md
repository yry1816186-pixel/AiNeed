<objective>
Style DNA social matching backend: compute user style vectors from interaction history, store in Qdrant user_style_dna collection, and provide top-K cosine similarity matching.

Purpose: Users can discover other people with similar fashion taste. The style DNA is a weighted average of FashionSigLIP vectors from items the user has interacted with (purchase weight=3, favorite=2, view=1). The matching results only expose non-PII data.

Output: (1) Python StyleDNAService with vector aggregation and Qdrant-based matching; (2) FastAPI endpoints for compute and match; (3) NestJS proxy controller and service with JWT auth; (4) Test coverage for all components.
</objective>

       - `async def update_user_vector(self, user_id: str, item_vectors: list[list[float]], weights: list[float])`:
         - Compute weighted average: `weighted = sum(vec * w for vec, w in zip(item_vectors, weights)) / sum(weights)`
         - Normalize: `weighted /= np.linalg.norm(weighted)`
         - Upsert as `VectorDocument(doc_id=user_id, content=f"user_style_dna:{user_id}", embedding=weighted.tolist(), metadata={"user_id": user_id, "method": "weighted_avg"})`

         - Get user vector from Qdrant by searching for doc_id == user_id (use `_client.retrieve()` or search with filter)
         - If no vector found, return empty list (cold start)
         - Search in user_style_dna collection with top_k+1 (to exclude self)
         - Filter out result where doc_id == user_id
