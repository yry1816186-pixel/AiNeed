<objective>
Backend support for WeChat mini-program authentication and photo-based image vector search.

Purpose: The mini-program needs a dedicated login endpoint that uses jscode2session (different from the existing OAuth-based wechat login). The photo search feature needs a Python FastAPI image embedding + Qdrant search endpoint that the NestJS backend can proxy to.

Output: (1) New /auth/wechat-mini endpoint with jscode2session support; (2) New /api/vector/search/image endpoint for image upload -> FashionSigLIP encode -> Qdrant search; (3) Extended AuthProvider enum with wechat_mini.
</objective>

| Boundary                                 | Description                                   |
| ---------------------------------------- | --------------------------------------------- |
| Mini-program client -> /auth/wechat-mini | Untrusted wx.login code from WeChat client    |

| Backend -> WeChat jscode2session API     | External API call with app secret             |

## STRIDE Threat Register

| Threat ID | Category               | Component               | Disposition | Mitigation Plan                                                                                                                |
| --------- | ---------------------- | ----------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| T-08-01   | Spoofing               | /auth/wechat-mini       | mitigate    | Rate limit 5/min + validate jscode format (should be non-empty string, max 128 chars)                                          |
| T-08-02   | Tampering              | /search/image upload    | mitigate    | Validate file content_type starts with image/ + max 10MB + PIL Image.open verification (will throw on corrupt/malicious files) |
| T-08-03   | Information Disclosure | WeChat app secret       | accept      | Secret stored in env var, not in code; same pattern as existing WECHAT_APP_SECRET                                              |
| T-08-04   | Denial of Service      | /api/vector/embed/image | mitigate    | Rate limit + file size limit 10MB + EmbeddingService lazy-load prevents cold-start flood                                       |

</threat_model>
