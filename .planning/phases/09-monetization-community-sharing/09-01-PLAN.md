| ----------------- | ----------------------------------------------------------------- |
| Client -> API     | Untrusted client sends requests that may attempt to bypass limits |
| API -> Redis      | Trusted internal connection for atomic counter operations         |
| API -> PostgreSQL | Trusted internal connection for subscription status checks        |

## STRIDE Threat Register

| Threat ID | Category  | Component              | Disposition | Mitigation Plan                                                 |
| --------- | --------- | ---------------------- | ----------- | --------------------------------------------------------------- |
| T-09-01   | Tampering | UsageLimitGuard        | mitigate    | Backend Guard enforces limits; frontend cannot bypass (D-04)    |
| T-09-02   | Tampering | Redis key format       | mitigate    | Key includes userId from JWT token, not from request body       |
| T-09-03   | Denial    | Redis counter overflow | accept      | Redis INCR uses 64-bit int; no realistic overflow at 5/day/user |
| T-09-04   | Spoofing  | Subscription bypass    | mitigate    | Guard queries UserSubscription from DB, not from client claims  |
| T-09-05   | Tampering | X-Usage-\* headers     | accept      | Headers are informational only; enforcement is server-side      |
