# Plan 05-01: Pre-cache Endpoint + Warmup Validation

**Goal:** Implement the missing demo pre-cache API and extend warmup validation to verify cache integrity.

## Tasks

### Task 1: Implement `POST /api/v1/demo/pre-cache` Backend Controller

<action>
Create a new controller + service in `apps/backend/src/domains/mobile-api/`:

1. Create `demo-cache.controller.ts` with route `POST /api/v1/demo/pre-cache`:

   - Endpoint accepts no request body
   - Returns JSON: `{ status, cachedItems: { recommendations: N, ttsPhrases: N, sceneConfigs: N } }`

2. Create `demo-cache.service.ts`:

   - `preCacheRecommendations()`: For all 10 seed profiles from `docs/PRESENTATION/seed-user-data-v2.json`, call AI service to pre-generate top-5 outfit recommendations per scene (interview, date, casual, formal, sport). Store serialized JSON to Redis with key `demo:cache:rec:{profileId}:{scene}` and TTL 3600s.
   - `preCacheTtsPhrases()`: Call `POST /api/v1/tts/precache` and verify all 14 phrases generate audio files to MinIO/disk.
   - `preCacheSceneConfigs()`: Serialize scene configuration objects to Redis key `demo:cache:scenes` with TTL 3600s.
   - Return summary with counts.

3. Add DTO: `DemoPreCacheResponseDto` with fields: `status: 'success' | 'partial'`, `recommendations: number`, `ttsPhrases: number`, `sceneConfigs: number`, `errors: string[]`.

4. Register module in `mobile-api.module.ts` imports array.

5. Add `DEMO_CACHE_*` entries to `apps/backend/.env.example`:
   - `DEMO_CACHE_TTL=3600`
   - `DEMO_CACHE_REDIS_PREFIX=demo:cache:`
