## 二、重点推荐

### 1. anilsenay/React-Native-Shopping-App — Dribbble 品质复刻

- 直接复刻 Dribbble Bright App UI Kit
- 视觉品质最接近设计稿的开源实现
- ProductDetail 页面布局和 Category 浏览交互模式可 1:1 借鉴

### 2. santervo/travel-destinations — 动效标杆

- Parallax Scroll 效果精美，可直接用于穿搭推荐页
- Shared Element Transition 实现参考价值极高
- Gesture-driven 交互动画模式

### 3. zxcodes/Shopzy — 架构典范

- TypeScript + Zustand 架构最规范
- 电商全流程完整
