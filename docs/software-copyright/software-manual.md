# 寻裳智能穿搭推荐系统 V1.0 — 软件说明书

## 一、软件概述

寻裳智能穿搭推荐系统（XUNO）是一款面向全年龄段用户的 AI 驱动穿搭决策平台。系统通过智能推荐引擎、AI 造型师对话、虚拟试穿等核心功能，帮助用户解决日常穿搭决策难题，实现从"不知道穿什么"到"自信出门"的完整体验闭环。

### 核心价值主张

- **体验壁垒替代技术壁垒**：以 AI 角色"伊伊"为核心交互入口，打造有温度的穿搭决策体验
- **场景化推荐**：基于天气、日程、场景的精准推荐，而非简单的商品罗列
- **对话式决策**：通过自然语言对话逐步逼近最优穿搭方案
- **试穿即购买**：虚拟试穿后一键购买，缩短决策到行动的距离

## 三、核心工作流程

### 3.1 每日推荐流程

1. 用户打开 App，进入 Today 页面
2. 系统获取用户位置和当日天气
3. 推荐编排器启动 6 层漏斗：
   - 第 1 层：场景过滤（天气+日程 → 筛选适配场景的服装）
   - 第 2 层：风格匹配（用户风格画像 → 匹配风格标签）
   - 第 3 层：体型适配（用户体型数据 → 筛选合身版型）
   - 第 4 层：色彩协调（色彩季型 → 协调配色方案）
   - 第 5 层：价格区间（用户预算 → 过滤价格范围）
   - 第 6 层：个性化排序（SASRec 序列推荐 → 最终排序）
4. 伊伊推送 3-5 套穿搭方案
5. 用户可对话调整或直接试穿

### 3.2 AI 造型师对话流程

1. 用户进入 Stylist 页面或点击语音按钮
2. DialogEngine 初始化为 SCENE 状态
3. 系统询问场景需求（"今天有什么安排？"）
4. 用户回答后，提取场景 slot，切换到 DIRECT 状态
5. 系统基于场景推荐穿搭方案
6. 用户可继续对话调整（CHAT 状态）
7. 支持虚拟试穿预览
8. 满意后一键购买

### 3.3 虚拟试穿流程

1. 用户选择商品和自己的照片
2. 系统检查用户是否已授权 photos 同意
3. 照片上传至 MinIO 加密存储
4. 调用 Python 试穿服务生成效果图
5. 返回带水印的预览图
6. 用户确认后可查看无水印版本
7. 照片 30 天后自动删除

## 四、用户指南

### 4.1 首次使用（Onboarding）

1. **场景选择**：选择常穿场景（日常/职场/约会/运动/社交）
2. **快速画像**：填写年龄、身高、体重、服装偏好
3. **风格表达**：通过视觉选择测试确定风格倾向
4. **首套推荐**：伊伊基于以上信息推荐第一套穿搭

### 4.2 隐私授权

首次使用时，系统会弹出隐私授权弹窗，需单独授权：

- 允许使用三围数据推荐（必选）
- 允许使用照片进行试穿（必选）
- 允许使用体脂率数据（可选）
- 确认使用国产 AI 服务，数据不跨境（必选）

用户可随时在"我的 → 设置 → 隐私授权"中管理授权。

### 4.3 日常使用

- **Today**：查看当日推荐方案，一键试穿或购买
- **Discover**：浏览推荐流，收藏灵感
- **Stylist**：与伊伊对话，获取个性化穿搭建议
- **Me**：管理衣橱、查看订单、设置偏好

### 4.4 数据管理

- **数据导出**：在设置中申请导出全部个人数据（JSON/CSV 格式）
- **账户删除**：在设置中申请删除账户及所有关联数据
- **授权管理**：随时撤回或重新授予各项隐私授权

## 六、安全与合规

### 6.1 数据安全

- 所有敏感数据传输使用 TLS 1.3 加密
- 个人信息存储使用 AES-256 加密
- 照片存储在加密对象存储中，30 天自动删除
- 数据库访问通过 Prisma ORM 防止 SQL 注入

### 6.2 PIPL 合规

- 敏感个人信息单独授权（第 29 条）
- 国产 AI 服务数据不跨境确认
- 支持数据导出（第 45 条）
- 支持账户删除（第 47 条）
- 同意版本管理（GB/T 45574-2025）
- 完整审计追踪

### 6.3 AI 服务合规

- 大语言模型：智谱 AI GLM-4-Flash（主） + GLM-5（自动降级），国内服务商
- 向量检索：Marqo FashionSigLIP（国内部署）
- 语音合成：Edge-TTS（微软中国节点）
- 所有 AI 服务数据不出境
