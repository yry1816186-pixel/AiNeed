## 软件说明

### 功能概述

寻裳智能穿搭推荐系统（XUNO）是一款 AI 驱动的全年龄段穿搭决策平台。核心交互模式为：用户打开 App 后，AI 角色"伊伊"主动推送当日穿搭方案，通过对话逼近最优决策，支持虚拟试穿，最终形成购买闭环。

### 核心功能模块

1. **场景化推荐引擎**

   - 基于天气、日程、场景的智能推荐
   - 6 层漏斗筛选机制：场景过滤 -> 风格匹配 -> 体型适配 -> 色彩协调 -> 价格区间 -> 个性化排序
   - 支持日常/职场/约会/运动/社交等多场景

2. **AI 造型师对话系统**

   - Agent 状态机驱动（SCENE/DIRECT/CHAT 三态切换）
   - 基于 GLM-4-Flash 大语言模型的自然语言交互（含 GLM-5 自动降级）
   - 多轮对话逼近最优穿搭决策
   - 语音交互支持（Edge-TTS 语音合成）

3. **虚拟试穿服务**

   - 用户照片与商品图片的智能融合
   - 支持多角度试穿效果预览
   - 试穿结果水印保护

4. **智能衣橱管理**

   - 衣物自动分类与标签管理
   - 穿搭方案保存与复用
   - 灵感收藏与策展空间

5. **风格测试与画像**

   - 4 步 Onboarding 流程：场景选择 -> 快速画像 -> 风格表达 -> 首套推荐
   - 体型/肤色/脸型/色彩季型分析
   - 偏好权重持续学习

6. **电商闭环**

   - 商品浏览与搜索
   - 购物车与订单管理
   - 支付集成（支付宝/微信）
   - 优惠券与促销系统

7. **社区与顾问**

   - 穿搭分享社区
   - 专业造型师在线咨询
   - 预约与评价系统

8. **数据合规与隐私保护**
   - PIPL 合规同意管理
   - 敏感信息单独授权
   - 数据导出与账户删除
   - 国产 AI 服务数据不跨境确认

### 技术特点

1. **FashionSigLIP 向量检索**：采用 Marqo-FashionSigLIP 模型进行服装特征提取与相似度检索，实现语义级别的商品匹配

2. **SASRec 序列推荐**：基于自注意力机制的序列推荐算法，捕捉用户行为序列中的时序模式，提升推荐精准度

3. **Agent 状态机对话引擎**：SCENE/DIRECT/CHAT 三态状态机驱动 AI 造型师对话，结合规则引擎与大语言模型实现可控对话流程

4. **6 层推荐漏斗**：场景过滤 -> 风格匹配 -> 体型适配 -> 色彩协调 -> 价格区间 -> 个性化排序，层层精炼推荐结果

5. **偏好权重持续学习**：基于用户行为反馈（浏览/点击/收藏/购买/试穿）实时更新偏好权重，实现推荐结果的动态优化

- **前端**：React Native 0.76.8 (Expo 52) / TypeScript 5.x

- **AI 服务**：Python FastAPI / GLM-4-Flash（含 GLM-5 自动降级） / FashionSigLIP / SASRec / Edge-TTS
- **存储**：MinIO 对象存储 / Qdrant 向量数据库
- **构建**：Turborepo / pnpm monorepo
