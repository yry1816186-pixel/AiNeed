## 二、算法概述

### 2.1 算法目的

寻裳智能穿搭推荐算法旨在为用户提供个性化的穿搭推荐服务。算法基于用户画像、场景需求、商品特征等多维度信息，通过 6 层漏斗筛选机制，从海量商品中筛选出最符合用户需求的穿搭方案。

### 2.2 算法适用场景

- 每日穿搭推荐（基于天气、日程、场景）
- AI 造型师对话推荐（基于对话上下文）
- 发现页个性化内容排序
- 搜索结果个性化排序
- 社区内容推荐

### 2.3 服务对象

全年龄段穿搭需求用户，包括但不限于：

- 日常通勤穿搭需求用户
- 特殊场景（约会、面试、社交）穿搭需求用户
- 时尚爱好者与风格探索者

## 三、算法原理

### 3.1 整体流程

```
用户输入                    特征提取                    漏斗筛选                    排序输出
+----------+            +------------+            +------------+            +----------+
| 场景需求 |            | 用户画像   |            | 第1层:场景 |            |          |
| 风格偏好 | ------->   | 商品特征   |  ------->  | 第2层:风格 |  ------->  | 个性化   |
| 体型数据 |            | 上下文信息 |            | 第3层:体型 |            | 排序结果 |
| 预算范围 |            | 行为序列   |            | 第4层:色彩 |            |          |
+----------+            +------------+            | 第5层:价格 |            +----------+
                                                  | 第6层:排序 |
                                                  +------------+
```

### 3.2 特征提取

#### 3.2.1 用户画像特征

| 特征维度 | 数据来源                 | 提取方式               |
| -------- | ------------------------ | ---------------------- |
| 体型特征 | 用户输入/照片分析        | 结构化数据直接使用     |
| 风格偏好 | Onboarding 测试/行为学习 | FashionSigLIP 语义嵌入 |
| 色彩偏好 | 色彩季型测试/历史行为    | 色彩向量空间映射       |
| 价格偏好 | 用户设置/购买历史        | 统计分布建模           |
| 场景偏好 | Onboarding 选择/使用行为 | 多热编码               |

#### 3.2.2 商品特征

| 特征维度 | 数据来源            | 提取方式                        |
| -------- | ------------------- | ------------------------------- |
| 视觉特征 | 商品图片            | FashionSigLIP 向量嵌入 (768 维) |
| 文本特征 | 商品名称/描述/标签  | 文本语义嵌入                    |
| 属性特征 | 分类/颜色/材质/季节 | 结构化编码                      |
| 价格特征 | 商品价格            | 归一化数值                      |

#### 3.2.3 行为序列特征

采用 SASRec（Self-Attentive Sequential Recommendation）模型对用户行为序列建模：

- 输入：用户历史行为序列（浏览/点击/收藏/购买/试穿）
- 模型：基于自注意力机制的序列编码器
- 输出：用户当前兴趣表示向量
- 更新：实时增量更新，支持在线学习

### 3.3 六层漏斗筛选

| 层级 | 名称       | 输入     | 筛选逻辑                        | 输出           |
| ---- | ---------- | -------- | ------------------------------- | -------------- |
| 1    | 场景过滤   | 场景标签 | 匹配天气/日程/场合标签          | 场景适配商品集 |
| 2    | 风格匹配   | 风格向量 | FashionSigLIP 余弦相似度 > 阈值 | 风格匹配商品集 |
| 3    | 体型适配   | 体型数据 | 版型-体型匹配规则               | 合身商品集     |
| 4    | 色彩协调   | 色彩季型 | 色彩搭配规则+向量距离           | 配色协调商品集 |
| 5    | 价格区间   | 预算范围 | 价格区间过滤                    | 预算内商品集   |
| 6    | 个性化排序 | 行为序列 | SASRec 打分 + 多样性约束        | 最终推荐列表   |

### 3.4 排序算法

最终排序综合以下信号：

```
最终分数 = w1 * SASRec_score        (序列推荐分)
         + w2 * similarity_score    (风格相似度)
         + w3 * freshness_score     (新品加权)
         + w4 * popularity_score    (热度加权)
         + w5 * diversity_penalty   (多样性惩罚)
```

权重通过 A/B 测试动态调整，确保推荐结果的准确性和多样性平衡。

## 四、模型信息

### 4.1 FashionSigLIP (Marqo-FashionSigLIP)

- **用途**：服装图片和文本的语义向量嵌入
- **模型来源**：基于 SigLIP 架构，在时尚领域数据上微调
- **部署方式**：本地部署，服务器位于中国境内
- **输入**：图片(PNG/JPEG) / 文本(中英文)
- **输出**：768 维向量
- **数据范围**：仅处理用户授权的图片和商品数据

### 4.2 SASRec (Self-Attentive Sequential Recommendation)

- **用途**：用户行为序列建模与推荐排序
- **模型来源**：基于 Kang & McAuley (2018)论文实现
- **部署方式**：本地部署，服务器位于中国境内
- **输入**：用户行为序列（item ID 列表）
- **输出**：候选商品排序分数
- **训练数据**：脱敏后的用户行为日志

### 4.3 GLM-4-Flash (智谱 AI)

- **用途**：AI 造型师对话生成
- **模型来源**：智谱 AI (Zhipu AI) 大语言模型
- **部署方式**：API 调用，服务器位于中国境内
- **输入**：对话上下文 + 系统提示词
- **输出**：自然语言回复
- **数据范围**：仅处理用户主动输入的对话内容

## 五、数据流程

### 5.1 数据输入

| 数据类型 | 收集方式         | 存储位置          | 保留期限   |
| -------- | ---------------- | ----------------- | ---------- |
| 用户画像 | 用户主动填写     | PostgreSQL (加密) | 账户存续期 |
| 用户照片 | 用户主动上传     | MinIO (加密)      | 30 天      |
| 行为数据 | 自动采集         | PostgreSQL        | 1 年       |
| 对话记录 | 用户主动输入     | PostgreSQL (加密) | 6 个月     |
| 位置信息 | 系统获取(需授权) | 内存(仅天气查询)  | 不存储     |

### 5.2 数据处理

1. 用户数据经加密传输至服务端
2. 特征提取在内存中完成，不持久化中间结果
3. 模型推理结果缓存至 Redis，TTL 24 小时
4. 原始数据与推理结果物理隔离存储

### 5.3 数据输出

- 推荐结果（商品列表 + 推荐理由）
- 穿搭方案（搭配组合 + 适配分析）
- 对话回复（自然语言文本 + 语音）

## 六、安全措施

### 6.1 数据安全

- 传输加密：TLS 1.3
- 存储加密：AES-256（敏感字段应用层加密）
- 访问控制：RBAC + 最小权限原则
- 审计日志：全量操作审计追踪
- 数据脱敏：日志和监控中自动脱敏 PII 字段

### 6.2 模型安全

- 输入验证：严格校验所有模型输入格式和范围
- 输出过滤：GLM-4 输出经内容安全审核
- 模型隔离：AI 服务独立部署，与业务服务网络隔离
- 降级策略：模型不可用时自动降级为规则推荐

### 6.3 系统安全

- 网络安全：VPC 隔离 + 安全组 + WAF
- 身份认证：JWT + Refresh Token 轮换
- 接口防护：限流 + 防重放 + 参数签名
- 漏洞管理：定期安全扫描 + 依赖更新
