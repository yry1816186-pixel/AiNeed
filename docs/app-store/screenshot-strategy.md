### 截图工具

- ADB: `adb shell screencap -p /sdcard/screenshot.png && adb pull /sdcard/screenshot.png`
- Android Studio: Logcat 面板旁的截图按钮
- 模拟器: Extended Controls -> Screenshot

### 品牌装饰

- 边框色: 暖驼色 #C4956A
- 底部文字条: 深炭灰 #2D3436 背景 + 白色 #FFFFFF 功能说明文字
- 字体: 系统默认中文字体
- Logo: 右上角放置寻裳 Logo (透明背景)

### 截图标注规范

每张截图底部添加 44px 高度的深色条带，包含:

- 左侧: 功能图标 (圆角方形底色 #C4956A)
- 右侧: 功能名称 (白色 16sp)

示例: `[🎨] AI 造型师推荐` / `[👗] 虚拟试穿` / `[📅] 7天穿搭日历`
