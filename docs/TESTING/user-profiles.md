## 招募要求

1. **体型匹配**: 优先选择真实体型匹配的用户，确保推荐逻辑可验证
2. **场景真实**: 用户近期有对应场景需求（如真的在求职/约会/旅行）
3. **多样性**: 时尚敏感度从低到高覆盖，避免全是时尚达人
4. **设备统一**: 统一使用 Android 测试机，避免设备差异
5. **时间充裕**: 确保用户能完成 35-45 分钟完整测试
