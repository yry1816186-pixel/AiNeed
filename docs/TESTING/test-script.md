# 寻裳 XUNO — 种子用户测试脚本

> **版本**: v1.0
> **适用**: 5 人种子用户测试
> **时长**: 每人 35-45 分钟
> **测试环境**: Android 真机 + 后端 Dev 环境 + 黄金推荐数据

---

## 测试前准备

### 环境检查清单

- [ ] 后端服务运行正常 (`cd apps/backend && pnpm dev`)
- [ ] 移动端 Debug APK 已安装
- [ ] 黄金推荐数据已加载（5 种 Profile×3 套方案）
- [ ] 测试账号可用（test@example.com / Test123456!）
- [ ] 录屏工具就绪（ADB screenrecord 或系统录屏）
- [ ] 反馈表打印/电子版就绪
- [ ] 计时器准备

### 测试员须知

1. **不帮助、不引导** — 用户卡住时只说"你想怎么做就怎么做"
2. **鼓励出声思考** — "你能说说你现在在想什么吗？"
3. **记录一切** — 耗时、点击、犹豫、表情、自言自语
4. **不解释功能** — 测试的是可发现性，不是教学效果
5. **中断规则** — 用户连续卡住超过 2 分钟，可提示"你可以试试其他方式"

## 任务 A: Onboarding 画像建立

> **目标**: 验证新用户能否独立完成注册 →Onboarding→ 获得首次推荐

### 操作步骤

| 步骤 | 用户行为                                                          | 观察点                           |
| ---- | ----------------------------------------------------------------- | -------------------------------- |
| A1   | 打开 App，进入注册/登录页                                         | 首屏理解度、注册流程是否顺畅     |
| A2   | 完成注册或登录                                                    | 表单填写是否顺利、验证码是否收到 |
| A3   | 进入 Onboarding 流程（基本信息 → 风格测试 → 场景选择 → 体型照片） | 每步停留时间、是否理解每步目的   |
| A4   | 完成风格测试（选择偏好图片）                                      | 选择是否犹豫、是否理解图片含义   |
| A5   | 选择日常场景（面试/约会/通勤/旅行等）                             | 场景理解度、是否找到自己需要的   |
| A6   | 上传或拍摄体型照片                                                | 拍照引导是否清晰、是否愿意上传   |
| A7   | 查看画像生成结果                                                  | 是否认可分析结果、是否理解各维度 |

### 预期结果

- 用户在 5 分钟内完成全部 Onboarding 步骤
- 画像结果页展示体型分析、色彩季型、风格标签
- 自动跳转至首页推荐

### 评分标准

| 指标       | 优秀 (5)         | 良好 (3)              | 需改进 (1)    |
| ---------- | ---------------- | --------------------- | ------------- |
| 完成率     | 100% 完成        | 部分完成（跳过 1 步） | 放弃或需帮助  |
| 完成耗时   | ≤3 分钟          | 3-5 分钟              | >5 分钟       |
| 错误操作   | 0 次             | 1-2 次                | ≥3 次         |
| 主观满意度 | 用户主动表示顺畅 | 无抱怨                | 表达困惑/不满 |

## 任务 B: AI 造型师对话

> **目标**: 验证用户能否与伊伊自然对话并获得穿搭推荐

### 操作步骤

| 步骤 | 用户行为                                  | 观察点                                 |
| ---- | ----------------------------------------- | -------------------------------------- |
| B1   | 找到并进入 AI 造型师对话界面              | 入口可发现性                           |
| B2   | 发起对话："帮我搭一套面试穿搭"            | 表达方式是否自然、伊伊是否理解         |
| B3   | 根据伊伊追问补充信息（场景/预算/偏好）    | 追问是否合理、用户是否理解追问意图     |
| B4   | 查看伊伊生成的穿搭方案                    | 方案是否满足需求、用户是否理解推荐理由 |
| B5   | 尝试修改方案（"换一件上衣"/"预算低一点"） | 伊伊是否理解修改意图、新方案是否合理   |
| B6   | 查看方案中的单品详情                      | 是否点击查看单品、匹配度分析是否理解   |

### 预期结果

- 伊伊在 2-3 轮对话内生成完整穿搭方案
- 方案包含 3-5 件单品，附带推荐理由
- 修改请求能被正确理解和响应

### 评分标准

| 指标       | 优秀 (5)               | 良好 (3)          | 需改进 (1)          |
| ---------- | ---------------------- | ----------------- | ------------------- |
| 对话轮数   | ≤3 轮获得方案          | 4-5 轮            | >5 轮或未获得       |
| 回复质量   | 精准理解+推荐合理      | 基本理解+部分合理 | 理解偏差/推荐不相关 |
| 修改响应   | 一次修改成功           | 2 次修改成功      | 修改后仍不满意      |
| 对话自然度 | 用户表达"像和朋友聊天" | 可以接受          | 表达"像机器人"      |

## 任务 C: 推荐方案与匹配度分析

> **目标**: 验证用户能否理解推荐方案的匹配度可视化

### 操作步骤

| 步骤 | 用户行为                                   | 观察点                                 |
| ---- | ------------------------------------------ | -------------------------------------- |
| C1   | 浏览推荐方案列表                           | 是否理解方案差异、是否知道如何选择     |
| C2   | 查看某方案的匹配度雷达图                   | 是否理解各维度含义、是否认可评分       |
| C3   | 对比两个方案的匹配度差异                   | 是否能发现差异、是否据此做出选择       |
| C4   | 查看推荐理由（体型适配/场景匹配/色彩协调） | 是否理解"为什么推荐这套"               |
| C5   | 查看单品替换建议                           | 是否使用替换功能、替换后匹配度是否变化 |

### 预期结果

- 推荐方案页展示 3 套方案，含雷达图和匹配度分数
- 用户能理解至少 3 个维度的含义
- 单品替换功能可用

### 评分标准

| 指标         | 优秀 (5)         | 良好 (3)        | 需改进 (1)    |
| ------------ | ---------------- | --------------- | ------------- |
| 雷达图理解   | 自主理解全部维度 | 理解 2-3 个维度 | 完全不理解    |
| 方案选择     | 基于匹配度做选择 | 凭感觉选择      | 无法选择      |
| 推荐理由认可 | 认可并觉得有用   | 部分认可        | 不认可/不理解 |
| 替换功能使用 | 自主发现并使用   | 提示后使用      | 不会使用      |

## 任务 D: 虚拟试衣

> **目标**: 验证用户能否完成拍照 → 试衣 → 查看效果的完整流程

### 操作步骤

| 步骤 | 用户行为               | 观察点                                 |
| ---- | ---------------------- | -------------------------------------- |
| D1   | 从推荐方案进入虚拟试衣 | 入口可发现性                           |
| D2   | 拍摄或上传全身照       | 拍照引导是否清晰、照片质量反馈是否理解 |
| D3   | 等待试衣效果生成       | 等待过程是否有进度提示、用户耐心如何   |
| D4   | 查看试衣效果图         | 效果是否自然、用户是否认可             |
| D5   | 切换不同方案试穿       | 是否尝试多套对比                       |
| D6   | 保存或分享试衣效果     | 是否有保存/分享意愿                    |

### 预期结果

- 拍照引导清晰，用户 1 次拍摄即可通过质量检测
- 试衣效果在 30 秒内生成
- 效果图自然度可接受

### 评分标准

| 指标       | 优秀 (5)          | 良好 (3)     | 需改进 (1)          |
| ---------- | ----------------- | ------------ | ------------------- |
| 拍照成功率 | 1 次通过          | 2-3 次通过   | >3 次或放弃         |
| 等待耐心   | 安静等待          | 偶尔询问进度 | 表达不耐烦          |
| 效果认可度 | 表达惊喜/满意     | 基本可接受   | 表达不真实/失望     |
| 多套对比   | 主动尝试 2 套以上 | 尝试 1-2 套  | 只看 1 套或不感兴趣 |

## 任务 E: 衣柜管理与收藏

> **目标**: 验证用户能否管理个人衣柜并使用收藏功能

### 操作步骤

| 步骤 | 用户行为                 | 观察点                 |
| ---- | ------------------------ | ---------------------- |
| E1   | 进入衣柜页面             | 入口可发现性           |
| E2   | 添加一件已有服装到衣柜   | 添加流程是否顺畅       |
| E3   | 浏览衣柜中的服装         | 分类/筛选是否好用      |
| E4   | 收藏一套推荐方案         | 收藏操作是否直观       |
| E5   | 查看收藏列表             | 是否能找到已收藏内容   |
| E6   | 基于衣柜服装获取搭配建议 | 是否理解"衣柜搭配"功能 |

### 预期结果

- 衣柜页面展示已有服装，支持分类浏览
- 添加服装流程 ≤3 步
- 收藏功能一键完成

### 评分标准

| 指标       | 优秀 (5)       | 良好 (3)   | 需改进 (1)     |
| ---------- | -------------- | ---------- | -------------- |
| 添加流畅度 | 1 次成功添加   | 2-3 次尝试 | 无法完成       |
| 分类理解   | 自主使用分类   | 浏览后理解 | 不理解分类逻辑 |
| 收藏操作   | 1 次成功       | 2 次尝试   | 找不到收藏入口 |
| 衣柜搭配   | 主动使用并满意 | 使用但一般 | 不知道此功能   |
