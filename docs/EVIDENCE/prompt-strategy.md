# 证据 4: AI Prompt 策略文档

> 展示 prompt 从"模糊"到"精确"的迭代过程，证明人对 AI 的驾驭能力

## Prompt 迭代示例 1: AI 造型师系统提示词

### V1（太模糊，输出质量差）

```
你是一个穿搭顾问，帮助用户搭配衣服。
```

**问题**: 输出格式不统一，有时给建议，有时闲聊，无法结构化处理

### V2（有结构但不够具体）

```
你是一个叫小裳的AI造型师。帮助用户搭配衣服。
回复时使用JSON格式，包含：
- reply: 回复内容
- slots: 推荐的单品
- nextAction: 下一步动作
```

**问题**: slots 格式不统一，nextAction 范围不明确，关键词提取规则缺失

### V3（精确，输出质量高）

```
你是「小裳」，一位专业、温暖、有品味的AI造型师。

## 工作流程
1. 了解场景：用户要参加什么活动？什么场合？
2. 探索风格：用户偏好什么风格？有没有参考图？
3. 收集细节：身材特点、预算范围、颜色偏好
4. 给出方案：推荐具体搭配，解释为什么适合

## 输出格式
严格输出JSON：
{
  "reply": "自然语言回复",
  "slots": {
    "scene": "interview|date|travel|commute|seasonal|career",
    "style": "minimalist|casual|business|romantic|streetwear|bohemian",
    "bodyConcern": "用户提到的身材关注点",
    "budget": "预算范围",
    "colorPreference": ["颜色偏好"],
    "avoidItems": ["避免的单品"]
  },
  "nextAction": "ask_scene|ask_style|ask_body|ask_budget|recommend|refine",
  "confidence": 0.0-1.0
}

## 关键词提取规则
- 场景：面试、约会、旅行、通勤、换季、职场
- 风格：极简、休闲、商务、浪漫、街头、波西米亚
- 身材关注：不描述身体，只记录用户提到的穿衣困扰
- 预算：提取数字和单位
- 颜色：提取颜色偏好
- 避免：提取用户不想穿的单品

## 措辞原则
- 体正面措辞：描述服装特点，不描述身体缺陷
- 例如：不说"遮住粗腿"，说"选择A字裙营造流畅线条"
```

**结果**: 输出格式 100%符合预期，关键词提取准确率从 40%提升到 85%+

**代码证据**: `apps/backend/src/domains/ai-core/ai-stylist/prompts/system-prompt.ts`

## Prompt 迭代示例 2: 穿搭规则生成

### V1（太模糊，输出质量差）

```
帮我写一些穿搭规则，覆盖不同体型和场景
```

**问题**: 输出是自由文本，无法结构化存储，体型分类不统一

### V2（有结构但不够具体）

```
帮我写JSON格式的穿搭规则，每条规则包含：
体型、场景、推荐单品、避免单品、色彩建议
```

**问题**: 体型分类不统一（有时写"苹果型"有时写"O 型"），颜色格式混乱，avoid_items 过多

### V3（精确，输出质量高）

```
生成穿搭规则JSON，严格遵循以下格式：
{
  "id": "bt_{bodyType}_{occasion}",
  "body_type": "apple|pear|hourglass|rectangle|inverted-triangle",
  "occasion": "interview|date|travel|commute|seasonal|career",
  "strategy": "一句话策略，从衣服特点出发不描述身体",
  "recommended": {
    "tops": ["具体单品名"],
    "bottoms": ["具体单品名"],
    "shoes": ["具体单品名"]
  },
  "recommended_colors": ["#hex颜色"],
  "avoid_items": ["避免的单品"],
  "tips": "穿着建议，遵循体正面措辞",
  "formality": 0.0-1.0
}
注意：
1. 措辞遵循体正面原则：描述服装不描述身体
2. 每个bodyType-occasion组合至少一条
3. avoid_items不超过3个
4. 颜色必须是hex格式
```

**结果**: 生成 30 条规则，格式 100%符合要求，体正面措辞达标率 95%+

**代码证据**: `ml/services/stylist/stylist_prompts.py`

## Prompt 迭代示例 3: 虚拟试衣提示词

### V1（太模糊）

```
帮这个用户换上这件衣服
```

### V2（有细节但不够精确）

```
请将用户照片中的服装替换为目标服装。
保持用户的身体姿态和背景不变，只更换服装。
```

### V3（精确，包含约束和质量要求）

```
执行虚拟换装任务：
- 保持用户的面部特征、身体姿态、背景环境完全不变
- 仅替换服装部分，确保服装与身体自然贴合
- 保留光照和阴影的一致性
- 服装纹理和褶皱应符合自然物理效果
- 如果目标服装与用户原有服装风格差异大，优先保证自然感
输出：换装后的完整人物图像
```

**代码证据**: `apps/backend/src/domains/ai-core/try-on/services/glm-tryon.provider.ts`

## Prompt 策略总结

| 迭代阶段  | 特征                | 输出质量 | 典型问题               |
| --------- | ------------------- | -------- | ---------------------- |
| V1 模糊   | 一句话描述          | 20-30%   | 格式混乱、内容随机     |
| V2 结构化 | 指定输出格式        | 50-60%   | 枚举值不统一、约束不足 |
| V3 精确   | 格式+枚举+约束+示例 | 85%+     | 偶尔遗漏边缘情况       |

### 关键经验

1. **枚举值必须显式列出**：AI 不会自动推断枚举范围
2. **约束条件必须量化**："不超过 3 个"比"少量"有效
3. **体正面措辞需要示例**：仅说"体正面"AI 不理解，需要给出正反例
4. **输出格式必须给 JSON 模板**：自由描述格式 AI 会自行发挥
