# 寻裳 XUNO — Demo 录制指南

> 配合 `XUNO-DEMO-SCRIPT.md` 使用
> 目标: 产出一段 2:20 的流畅 Demo 视频，0 失误、0 空档

---

## 1. 录制设备和软件推荐

### 方案 A: 手机录屏（推荐，最真实）

| 设备    | 推荐        | 说明                                     |
| ------- | ----------- | ---------------------------------------- |
| iPhone  | iPhone 12+  | iOS 自带录屏，画质稳定                   |
| Android | 主流旗舰    | 需安装 AZ Screen Recorder 或系统自带录屏 |
| 电脑    | Windows/Mac | 用于投屏+OBS 录制（画面更大更清晰）      |

**手机录屏步骤（iOS）**:

1. 设置 → 控制中心 → 添加"屏幕录制"
2. 长按录屏按钮 → 开启麦克风（如需配音）
3. 从控制中心下拉开始录屏
4. 录完后在照片中找到视频，AirDrop 到电脑

**手机投屏到电脑录制（最佳方案）**:

- Windows: 使用 [LonelyScreen](http://www.lonelyscreen.com/) 或 [5KPlayer](https://www.5kplayer.com/) 接收 AirPlay
- Mac: QuickTime Player → 文件 → 新建电影录制 → 选择 iPhone
- 然后用 OBS 捕获电脑屏幕录制

### 方案 B: Android 模拟器录制

| 软件                    | 说明                               |
| ----------------------- | ---------------------------------- |
| Android Studio Emulator | 官方模拟器，可运行 Expo 构建的 APK |
| 夜神模拟器 / 雷电模拟器 | 更轻量，直接拖入 APK 安装          |
| OBS Studio              | 录制模拟器窗口，免费开源           |

**模拟器配置**:

1. 安装模拟器，分配 4GB RAM + 2 核 CPU
2. 安装 Expo 构建的 APK（`eas build --profile preview --platform android`）
3. 分辨率设为 1080×2400（主流手机尺寸）
4. 用 OBS 的"窗口捕获"录制模拟器窗口

### 方案 C: OBS Studio 直接录制（推荐用于最终版）

**OBS 设置**:

- 分辨率: 1920×1080
- 帧率: 30fps（流畅且文件小）
- 编码器: x264 或 NVENC（RTX 4060 可用 NVENC 硬编）
- 输出格式: MP4
- 码率: 5000-8000 Kbps

**OBS 场景设置**:

1. 场景 1: "手机投屏" — 窗口捕获（手机/模拟器画面）
2. 场景 2: "PPT 技术页" — 窗口捕获（PPT/Keynote）
3. 场景 3: "全屏 App" — 手机画面放大到全屏
4. 场景 4: "二维码" — 静态图片源

## 3. 录制注意事项

### 网络准备

| 项目     | 要求                       | 说明                |
| -------- | -------------------------- | ------------------- |
| 主网络   | 有线宽带/稳定 WiFi         | 确保 API 请求不超时 |
| 备用网络 | 手机热点                   | 准备好，随时切换    |
| DNS      | 114.114.114.114 或 8.8.8.8 | 避免 DNS 解析慢     |
| 测试     | 录制前完整跑一次 Demo      | 确保所有 API 可通   |

### 环境准备

| 项目     | 要求                                       |
| -------- | ------------------------------------------ |
| 手机电量 | 100%（录屏耗电快）                         |
| 通知     | 勿扰模式（关闭微信、短信等所有通知）       |
| 光线     | 如果拍摄手机屏幕，避免反光                 |
| 声音     | 如果录制旁白，使用安静环境+耳机麦克风      |
| 背景     | 手机壁纸设为纯色（避免录屏时露出隐私信息） |

### 时序控制

| 技巧          | 说明                                         |
| ------------- | -------------------------------------------- |
| 预加载        | 每个页面提前打开一次，让数据缓存住           |
| 节奏卡        | 打印节奏卡放在旁边，每完成一步勾选           |
| 计时器        | 手机设一个 2:20 的倒计时（静音震动提醒）     |
| 录 3 遍取最佳 | 第 1 遍熟悉，第 2 遍正式，第 3 遍补拍        |
| B-Roll        | 关键画面单独录制近景特写（雷达图、记忆气泡） |

## 5. 功能未接通的替代方案

### 替代策略总表

| 功能                  | 风险等级 | 替代方案              | 操作方式                             |
| --------------------- | -------- | --------------------- | ------------------------------------ |
| 伊伊对话/推荐         | 高       | 预录制视频 + 后期配音 | 提前跑一遍流程，录屏保存             |
| 匹配度雷达图          | 中       | PPT 截图 + 动画模拟   | 用 PPT 的雷达图动画替代              |
| "换一件"实时优化      | 中       | 两张截图前后对比      | 先截图低分版，再截图高分版，后期剪辑 |
| 跨场景记忆            | 高       | 预设对话数据          | 提前在后台设置好偏好数据             |
| 偏好面板展示          | 低       | PPT 截图              | 截图放入 PPT                         |
| 技术对比(FashionCLIP) | 低       | PPT 静态页面          | 已在 PPT 中准备                      |
| AI 试穿               | 低       | PPT 截图/视频         | 不在 Demo 中展示（时间不够）         |
| 二维码扫码            | 低       | PPT 静态二维码        | 已在 PPT 中准备                      |

### 具体替代操作

**如果伊伊对话 API 挂了**:

1. 切到 PPT 第 5 页（Demo 占位页）
2. 播放预录制的 Demo 视频（已准备好）
3. 声音: "由于现场网络原因，我们准备了预录制的 Demo 视频"

**如果推荐结果加载慢（>3 秒）**:

1. 提前加载一次，让数据缓存住
2. 录制时从缓存读取，速度会快很多
3. 如果还是慢，在后期剪辑中裁掉等待时间

**如果"换一件"不工作**:

1. 准备两张截图: 82%色彩版 和 91%色彩版
2. 用 PPT 淡入淡出切换两张截图
3. 演讲词不变，只是画面从实时变成截图

**如果跨场景记忆不工作**:

1. 在后台数据库中预设用户偏好: `preference: { neckline: 'exclude_turtle' }`
2. 预设"约会"场景的推荐结果中包含 V 领选项
3. 提前测试一遍确保伊伊会说"因为你说过不喜欢高领"

### Plan B: 完整预录制视频

如果现场网络完全不可用:

1. **提前录制**: 在家中/实验室用稳定网络录制完整 Demo
2. **视频规格**: MP4, 1080p, 30fps, 2:20
3. **后期处理**:
   - 用 CapCut 或 Premiere 添加时间戳标注
   - 在关键"哇"时刻添加放大/高亮效果
   - 底部添加进度条
4. **现场播放**: PPT 中嵌入视频，自动播放
5. **配音**: 可以现场配音（暂停视频音频），也可以预录
