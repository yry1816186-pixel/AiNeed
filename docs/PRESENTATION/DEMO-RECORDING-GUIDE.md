# 寻裳 XUNO -- Demo 录制指南（OBS + 模拟器方案）

> 配合 `XUNO-DEMO-SCRIPT.md` 使用
> 目标: 产出一段 2:20 的流畅 Demo 视频，0 失误、0 空档
> **最后更新**: 2026-04-26 (校准为 OBS + Android 模拟器方案)

## 1. 硬件/软件准备

### 必需

| 设备/软件      | 推荐配置                        | 说明                                   |

## 2. OBS 配置

### 录制参数

| 参数     | 推荐值                   | 说明                               |
| -------- | ------------------------ | ---------------------------------- |
| 分辨率   | 1920 x 1080 (1080p)      | 标准高清，比赛演示足够             |
| 帧率     | 30 fps                   | 流畅且文件小                       |
| 编码器   | NVENC (RTX 4060) 或 x264 | NVENC 硬件编码首选，CPU 占用低     |
| 码率     | 8000 Kbps (CBR)          | 清晰度与文件大小的平衡点           |
| 输出格式 | **MKV** (录制时)         | 防崩溃 -- MKV 即使录制中断也能恢复 |
| 最终格式 | **MP4** (后期转换)       | 通用播放格式，比赛设备兼容         |

### OBS 场景设置

**场景 1: "模拟器投屏"**

| 源类型   | 配置                                       |
| -------- | ------------------------------------------ |
| 窗口捕获 | 捕获 Android Emulator 窗口，自动匹配分辨率 |
| 音频     | 模拟器音频 (系统音频捕获)                  |

**场景 2: "画中画" (可选)**

| 源类型   | 配置                          |
| -------- | ----------------------------- |
| 窗口捕获 | 模拟器全屏 (主画面)           |
| 摄像头   | 右下角小窗，200x200，圆角蒙版 |

**场景 3: "PPT 技术页"**

| 源类型   | 配置                          |
| -------- | ----------------------------- |
| 窗口捕获 | PowerPoint / Keynote 全屏演示 |

**场景 4: "二维码"**

| 源类型 | 配置                 |
| ------ | -------------------- |
| 图片源 | 二维码静态图片，全屏 |

### OBS 快捷键

| 操作       | 快捷键 (建议) | 说明          |
| ---------- | ------------- | ------------- |
| 切换场景 1 | F1            | 模拟器投屏    |
| 切换场景 2 | F2            | 画中画 (可选) |
| 切换场景 3 | F3            | PPT 技术页    |
| 切换场景 4 | F4            | 二维码        |
| 开始/停止  | F12           | 录制控制      |

### MKV → MP4 转换

录制完成后，在 OBS 中直接转换（不损失质量）:

```
OBS → 文件 → 录制文件重新封装 → 选择 MKV → 输出 MP4
```

或使用 FFmpeg:

```bash
ffmpeg -i demo-raw.mkv -c copy demo-final.mp4
```

## 3. 模拟器配置

### Android Studio Emulator 设置

1. 打开 Android Studio → Virtual Device Manager
2. 创建虚拟设备: **Pixel 7** (1080 x 2400)
3. 系统镜像: **API 34** (Android 14)
4. 高级设置:
   - RAM: **4096 MB**
   - VM heap: **512 MB**
   - Graphics: **Hardware - GLES 2.0** (利用 RTX 4060)
   - 勾选 "Enable Device Frame" (让模拟器看起来像真手机)

### App 安装到模拟器

```bash
# 方式 1: Expo development build
eas build --profile preview --platform android
# 下载 APK 后拖入模拟器安装

# 方式 2: 直接运行 (开发模式)
cd apps/mobile
npx expo run:android
```

## 4. 录制步骤

### 录制前准备

1. **启动 Docker 全栈**:

   ```bash
   cd C:/AiNeed
   bash scripts/demo-local.sh
   # 等待所有 15 服务健康检查通过 (~2 分钟)
   ```

2. **启动 Android 模拟器 + App**

3. **执行预热脚本**:

   ```bash
   bash scripts/demo-warmup.sh
   # 健康检查 + 缓存预热
   ```

4. **使用测试账号登录** (seed profile #1 -- 面试穿搭场景)

5. **预跑一遍 Demo Script**: 按 `XUNO-DEMO-SCRIPT.md` 逐幕操作，确保每个功能正常

6. **启动 OBS**: 选择场景 1 (模拟器投屏)，确认画面正常

### 正式录制

1. **按 F12 开始录制**
2. **按 Demo Script 逐幕操作**:
   - 每幕之间暂停 2 秒 (留给后期剪辑空间)
   - 操作节奏与演讲词配合
   - 如有失误，不要停止，继续录制，后期剪辑处理
3. **完成所有 8 幕后按 F12 停止**
4. **重播检查**: 观看录制的视频，确认画面流畅、功能正常
5. **录 3 遍取最佳**: 第 1 遍熟悉，第 2 遍正式，第 3 遍补拍

### 录制注意事项

| 项目   | 要求                                        |
| ------ | ------------------------------------------- |
| 网络   | 使用本地 Docker，零外部网络依赖             |
| 通知   | Windows 勿扰模式，关闭所有通知弹窗          |
| 分辨率 | 模拟器窗口固定大小，不要拖动调整            |
| 鼠标   | 模拟器内操作用鼠标模拟触屏，动作平滑        |
| 计时器 | 手机设一个 2:20 倒计时 (静音震动提醒)       |
| B-Roll | 关键画面单独录制近景特写 (雷达图、记忆气泡) |

## 5. 后期剪辑

### 推荐工具

| 工具            | 平台    | 特点                    |
| --------------- | ------- | ----------------------- |
| 剪映专业版      | Windows | 免费，中文友好，AI 字幕 |
| DaVinci Resolve | Windows | 免费版功能强大          |

### 剪辑步骤

**1. 导入素材**

- 将 OBS 录制的 MKV 文件转为 MP4 (见第 2 节)
- 导入到剪辑软件时间线

**2. 添加旁白配音**

- 按 `VIDEO-SCRIPT.md` 的 [配音] 标注录制旁白
- 使用安静环境 + USB 麦克风
- 旁白音轨放在主视频音轨之上

**3. 添加字幕**

- 剪映: 使用 AI 自动识别旁白 → 手动校对
- DaVinci: 使用 Fusion 字幕工具
- 字幕样式: 底部居中，白字黑边，24px

**4. 添加片头片尾**

- 片头 (3 秒): XUNO Logo 动画 + "寻裳 -- 你的 AI 穿搭搭子"
- 片尾 (3 秒): 联系方式 + 二维码

**5. 添加背景音乐**

- 选择轻柔钢琴/吉他纯音乐
- 音量控制在 **20%** (不抢旁白)
- 推荐来源: 爱给网 / Pixabay 免费音乐

**6. 导出**

| 参数   | 推荐值       |
| ------ | ------------ |
| 格式   | MP4          |
| 编码   | H.264        |
| 分辨率 | 1920 x 1080  |
| 帧率   | 30 fps       |
| 码率   | 8000 Kbps    |
| 音频   | AAC 256 Kbps |

## 6. Backup 方案 (D-05: 必须预录 backup 视频)

### Backup 视频要求

- 2-3 分钟完整 Demo 视频
- 包含所有 8 幕的完美操作 (无失误)
- 包含旁白配音 + 字幕
- 文件格式: MP4, 1080p

### Backup 视频部署

1. **将最终 MP4 拷贝到**:

   - 演示用笔记本电脑桌面
   - 手机 (VLC 播放器打开)
   - USB 存储盘 (双备份)

2. **演示设备预装 VLC 播放器**

3. **Live demo 失败时零延迟切换**:

   | 步骤 | 操作                                     |
   | ---- | ---------------------------------------- |
   | 1    | 按空格键暂停当前画面                     |
   | 2    | Alt+Tab 切换到 VLC                       |
   | 3    | VLC 全屏播放 backup 视频                 |
   | 4    | 演讲词: "由于现场环境原因，请看预录视频" |

### 切换演练

- 演示前至少练习 3 次切换流程
- 确保 VLC 已打开并加载视频 (暂停在开头)
- 快捷键: VLC 全屏 = F 键，播放 = 空格键

## 8. 功能未接通的替代方案

### 替代策略总表

| 功能                     | 风险等级 | 替代方案               | 操作方式                          |
| ------------------------ | -------- | ---------------------- | --------------------------------- |
| 伊伊对话/推荐            | 高       | 预录制视频 + 后期配音  | 提前跑一遍流程，录屏保存          |
| 匹配度雷达图             | 低       | **已实现** -- 无需替代 | `MatchRadarChart.tsx` 五维雷达图  |
| "换一件"实时优化         | 低       | **已实现** -- 无需替代 | `ItemReplacementService` 基于画像 |
| 跨场景记忆               | 低       | **已实现** -- 无需替代 | `preferenceMemory` 跨会话持久化   |
| 偏好面板展示             | 低       | PPT 截图               | 截图放入 PPT                      |
| 技术对比 (FashionSigLIP) | 低       | PPT 静态页面           | 已在 PPT 中准备                   |
| AI 试穿                  | 低       | PPT 截图/视频          | 不在 Demo 中展示 (时间不够)       |
| 二维码扫码               | 低       | PPT 静态二维码         | 已在 PPT 中准备                   |

### 具体替代操作

**如果伊伊对话 API 挂了**:

1. 切到 PPT 第 5 页 (Demo 占位页)
2. 播放预录制的 Demo 视频 (已准备好)
3. 声音: "由于现场网络原因，我们准备了预录制的 Demo 视频"

**如果推荐结果加载慢 (>3 秒)**:

1. 提前加载一次，让数据缓存住
2. 录制时从缓存读取，速度会快很多
3. 如果还是慢，在后期剪辑中裁掉等待时间

**如果"换一件"不工作**:

1. 准备两张截图: 82%色彩版 和 91%色彩版
2. 用 PPT 淡入淡出切换两张截图
3. 演讲词不变，只是画面从实时变成截图

**如果跨场景记忆不工作**:

1. 在后台数据库中预设用户偏好: `preference: { neckline: 'exclude_turtle' }`
2. 预设"约会"场景的推荐结果中包含 V 领选项
3. 提前测试一遍确保伊伊会说"因为你说过不喜欢高领"

### Plan B: 完整预录制视频

如果现场网络完全不可用:

1. **提前录制**: 在家中/实验室用稳定网络录制完整 Demo
2. **视频规格**: MP4, 1080p, 30fps, 2:20
3. **后期处理**:
   - 用剪映或 DaVinci 添加时间戳标注
   - 在关键"哇"时刻添加放大/高亮效果
   - 底部添加进度条
4. **现场播放**: PPT 中嵌入视频，自动播放
5. **配音**: 可以现场配音 (暂停视频音频)，也可以预录
