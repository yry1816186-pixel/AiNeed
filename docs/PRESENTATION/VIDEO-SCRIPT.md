# 寻裳 XUNO — Demo 视频脚本 (1-3 分钟)

## 格式要求

- 工具: OBS 录屏 + 剪映配音
- 分辨率: 1080p
- 格式: MP4
- 背景音乐: 轻快科技风

## 脚本

### 开场 (10 秒)

[画面]: 寻裳 Logo 动画
[配音]: "寻裳 — 你的 AI 穿搭搭子伊伊"

### 第一幕: 零步决策体验 (30 秒)

[画面]: 打开 App -> Today Screen -> 伊伊推送 "明天 12C 面试推荐 3 套"
[配音]: "打开 App，伊伊已经为你准备好今天的穿搭方案。天气、场景、你的衣橱，她都考虑到了。"

### 第二幕: 面试穿搭 Agent (60 秒)

[画面]: 进入 Stylist Tab
[配音]: "告诉伊伊你要面试什么岗位，她会像朋友一样帮你挑选。"
[画面]: 对话流程: 什么公司? -> 互联网公司 / 什么岗位? -> 产品经理 / 预算? -> 1000 以内
[配音]: "三个问题，伊伊就能理解你的需求。"
[画面]: 展示 3 套方案 -> 点击试穿 -> 试穿效果
[配音]: "虚拟试穿让你看到效果，不喜欢可以随时调整。"
[画面]: 说"不喜欢正式的" -> 伊伊调整推荐
[配音]: "伊伊会记住你的偏好，越用越懂你。"

### 第三幕: 技术深度 (30 秒)

[画面]: 6 层漏斗可视化 + Profile 切换
[配音]: "背后是 6 层推荐漏斗和视觉大模型 FashionSigLIP，每个人看到的推荐都不一样。"

### 第四幕: 包容性设计 (20 秒)

[画面]: 切换不同体型/风格的用户 -> 推荐变化
[配音]: "我们相信，好的穿搭推荐不应该被性别和体型定义。"

### 收尾 (10 秒)

[画面]: 寻裳 Logo + "让每个人都能自信出门"
[配音]: "寻裳 — 让每个人都能自信出门"
