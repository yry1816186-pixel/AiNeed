## 可能的 Q&A 预备

### 技术类问题

**Q: FashionSigLIP 微调用了多少数据？训练多久？**

> "我们基于 Marqo-FashionSigLIP（2025 SOTA 视觉模型），使用 LoRA 对中国时尚数据进行微调。训练在 AutoDL GPU 上进行，单次约 15 元。微调后的模型在服装检索任务上 Recall@5 提升了约 18%。同时，我们实现了 GLM-4-Flash → GLM-5 的自动 fallback 路由，5 秒超时触发，确保 AI 推荐稳定性。具体细节可以看我们的 ADR-001 决策记录。"

**Q: 对话状态机怎么实现的？**

> "五阶段状态机: GREET（问候+场景识别）→ CONTEXT（体型/肤色/偏好采集）→ GENERATE（推荐生成+解释）→ ACTION（试穿/替换/收藏）→ WRAP（收尾）。支持 SCENE（场景推荐）、DIRECT（直接对话）、CHAT（闲聊）三种对话模式。状态存储在 Redis 中，TTL 3600 秒，支持即时更新和降级策略。内置 FashionRuleLoader 加载 264 条穿搭规则，StudioSignalDetector 检测 5 种工作室推荐信号。"

**Q: 推荐准确率有多少？**

> "推荐引擎采用 6 层漏斗架构：候选池 → 合规过滤 → 场景匹配 → 尺码匹配 → 预算匹配 → 风格匹配 → 衣橱去重。每层过滤都有独立评分。匹配度雷达图展示五维评分（体型/场景/色彩/风格/预算），综合分数基于 DecisionScoreService 的三维加权（fit 30% + style 30% + preference 40%）。同时支持 A/B 实验埋点验证效果。"

### 商业类问题

**Q: 你的盈亏平衡点怎么算的？**

> "月运营成本约 1,625 元——GLM-4-Flash 的 LLM 成本为零，虚拟试穿 API 是最大成本项约 1,125 元。按 5%的实际到手佣金率计算，5,000 月活用户时月收入约 2,600 元，可以覆盖成本。所有数字基于淘宝联盟和京东联盟的官方佣金率。"

**Q: 一个人怎么保证产品质量？**

> "AI 辅助下，21 天完成了 345 次提交、34 万行代码。但 AI 写代码，我做决策——5 个关键技术决策都记录在 ADR 里，每个决策都有'AI 建议了什么、我为什么否决/修改'的完整记录。代码审查修改率约 40%，关键模块 100%人工审查。"

### 社会价值类问题

**Q: 这个项目的社会意义是什么？**

> "中国每年 900 万毕业生，90%不知道面试穿什么。穿搭焦虑不仅浪费时间，还影响自信。XUNO 让每个人都能在 3 分钟内获得专业的穿搭建议，这不是奢侈品消费，是基本信心保障。第一份工作的第一印象，不应该因为穿错衣服而打折。"
