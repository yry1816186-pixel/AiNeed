# 寻裳 XUNO — 比赛 Demo 脚本

## 准备（赛前 10 分钟）

1. 启动后端: `pnpm dev`
2. 启动移动端: `pnpm dev:mobile`
3. 开启 Demo 模式: 设置 → 开发者选项 → Demo 模式
4. 预缓存推荐: Demo 模式开启后自动执行
5. 验证网络: 确认后端 API 可达

## Demo 流程（3 分钟）

### 第一层：体验革命（30 秒）

1. 打开 App → Today Tab
2. 展示伊伊主动推送："明天 12°C 面试推荐 3 套"
3. 点击语音按钮，说"帮我搭一套面试穿搭"
4. 伊伊实时响应，展示推荐方案

### 第二层：面试穿搭 Agent（60 秒）

1. 进入 Stylist Tab
2. 伊伊问："什么公司？" → 回答"互联网公司"
3. 伊伊问："什么岗位？" → 回答"产品经理"
4. 伊伊问："预算？" → 回答"1000 以内"
5. 展示 3 套方案，点击试穿
6. 说"不喜欢正式的" → 伊伊调整推荐

### 第三层：包容性展示（60 秒）

1. 点击左下角齿轮图标 → ProfileDebugPanel
2. 切换到"职场精英"Profile → 应用
3. 展示推荐结果变化（不同人不同结果）
4. 切换到"创意达人"Profile → 应用
5. 展示推荐结果再次变化
6. 展示 RecommendationFunnel 6 层漏斗

### 收尾（30 秒）

1. 回到 Today Tab
2. 展示完整用户旅程：注册 → Onboarding → 推荐 → 对话 → 试穿 → 保存
3. 强调技术亮点：6 层推荐漏斗 + FashionSigLIP + Agent 状态机

## 降级方案

- 网络断开: 使用预缓存数据
- LLM 不可用: 降级到规则引擎模板
- App 崩溃: 播放预录 Demo 视频

## Demo 视频要求

- 时长: 1-3 分钟
- 内容: 面试穿搭场景完整流程 + 漏斗可视化 + Profile 切换
- 工具: Android 屏幕录制或 ADB screenrecord
- 格式: MP4, 1080p
