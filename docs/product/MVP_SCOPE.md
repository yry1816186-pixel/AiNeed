# MVP_SCOPE.md

## XunO (寻裳) MVP 范围定义

### 已实现（可演示）

**核心AI功能**

- AI造型师对话 (GLM-4.5 LLM + RAG)
- 身体分析 (MediaPipe Pose)
- 季节色彩分析
- 虚拟试穿 API (需第三方图像生成)
- 推荐系统 (SASRec + 混合检索)
- Chinese-Fashion-CLIP 模型

**用户系统**

- 邮箱/手机/微信注册登录
- JWT 鉴权 + 刷新令牌
- 用户同意管理
- 个人资料与偏好

**时尚功能**

- 衣橱管理 CRUD
- 穿搭推荐
- 风格测试
- 场合搭配

**商业功能（仅API）**

- 购物车/订单模型
- 支付宝/微信支付集成代码
- 订阅模型

**平台功能**

- Admin 管理面板
- 社区动态
- 博主/KOL 档案
- 实时聊天 WebSocket

### 未实现（需外部依赖）

| 功能             | 阻塞原因           |
| ---------------- | ------------------ |
| 真实商品目录     | 无供应商 API       |
| 在线支付         | 无商户账号         |
| 短信验证         | 无阿里云短信账号   |
| 微信登录         | 无微信开放平台账号 |
| 虚拟试穿图像生成 | 需第三方 API       |

### MVP 就绪评估

- **技术架构**: ✅ 完整
- **AI 核心**: ✅ 可用（基于研究数据）
- **用户流程**: ✅ 注册→登录→造型→推荐 完整
- **商业闭环**: ❌ 无真实商品/支付
- **合规审查**: ❌ 待法务审查
