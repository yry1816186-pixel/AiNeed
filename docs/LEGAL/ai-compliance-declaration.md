## 一、AI 技术在软件开发中的使用说明

### 1.1 AI 辅助工具

在"寻裳 AI 智能穿搭推荐系统"（以下简称"本软件"）的开发过程中，开发团队使用了以下 AI 辅助工具：

| 工具               | 用途                             | 使用范围                           |
| ------------------ | -------------------------------- | ---------------------------------- |
| Claude (Anthropic) | 代码生成辅助、架构讨论、文档编写 | 后端模块、前端组件、测试用例、文档 |
| GitHub Copilot     | 代码补全、函数实现建议           | 日常编码辅助                       |

### 1.2 AI 的角色定位

**AI 在本软件开发中仅作为辅助工具，不构成创作主体。** 具体而言：

1. **代码生成辅助**：AI 工具根据开发者提供的详细需求描述、架构设计和接口规范，生成代码片段和模块骨架。所有 AI 生成的代码均经过人工审查、修改和验证。

2. **架构讨论**：开发者使用 AI 工具进行技术方案的讨论和对比分析，但所有架构决策、技术选型和设计取舍均由人类开发者独立完成。

3. **文档辅助**：AI 工具协助编写技术文档、API 文档和用户手册的初稿，开发者对内容进行审核、修正和完善。

4. **调试辅助**：AI 工具在排查技术问题时提供思路和建议，具体的问题定位、根因分析和修复方案由开发者独立完成。

### 1.3 AI 未参与的内容

以下内容完全由人类开发者独立完成，未使用 AI 工具：

- 软件的整体架构设计和系统设计
- 业务逻辑和算法设计的核心决策
- 用户体验设计和交互设计
- 数据库 Schema 设计
- API 接口设计和协议定义
- 时尚领域知识的整理和规则编写（264+ 条时尚搭配规则）
- 项目需求分析和功能规划
- 所有代码的最终审查、测试和验收
- 软件著作权申请材料的编写

## 二、AI 功能模块说明

本软件包含以下 AI 功能模块，均由人类开发者设计并实现：

### 2.1 AI 造型师对话

- **技术方案**：基于智谱 AI GLM-5 大语言模型的对话式穿搭咨询
- **人类设计内容**：对话状态机（GREET→CONTEXT→SCENE/DIRECT/CHAT→GENERATE→ACTION→WRAP）、用户画像融合策略、时尚知识库构建（264+ 条规则）、槽位提取逻辑、推荐结果后处理
- **AI 模型角色**：作为推理引擎执行人类设计的对话策略，生成符合约束的穿搭建议

### 2.2 色彩季型分析

- **技术方案**：基于 CIELAB 色彩科学体系的 12 季色彩分析
- **人类设计内容**：12 季分析体系设计、CIE Delta-E 2000 色差计算公式选型、ITA 角度分类标准、季节调色板设计、肤色检测算法
- **AI 模型角色**：本模块为纯算法实现，未使用 AI 生成模型

### 2.3 体型分析与适配

- **技术方案**：基于身体关键点的 5 种体型分类和适配评分
- **人类设计内容**：5 种体型分类标准、关键比例指标定义、适配评分算法设计
- **AI 模型角色**：本模块为纯算法实现，未使用 AI 生成模型

### 2.4 虚拟试穿

- **技术方案**：基于 GLM 多模态 API 的图像生成
- **人类设计内容**：预处理流程设计（姿态/光照/特征分析）、提示词工程、后处理流程、质量评估标准
- **AI 模型角色**：作为图像生成引擎执行人类设计的提示词策略

## 三、数据来源合规说明

### 3.1 训练数据

本软件调用的 AI 模型（GLM-5）由智谱 AI 公司训练和提供，本软件不自行训练任何 AI 模型。

### 3.2 用户数据处理

- 用户上传的照片仅用于当次分析，分析完成后不保留原始图像
- 用户画像数据存储在自有 PostgreSQL 数据库，PII 字段采用 AES-256-GCM 加密
- 用户数据不用于 AI 模型的训练或微调
- 用户可随时导出和删除个人数据（符合 PIPL/GDPR 要求）

### 3.3 第三方 API

| 服务提供商                 | 用途                 | 数据处理             |
| -------------------------- | -------------------- | -------------------- |
| 智谱 AI (open.bigmodel.cn) | GLM-5 对话和图像生成 | 遵循智谱 AI 服务协议 |
| 和风天气                   | 天气数据查询         | 仅查询，不存储       |
| 阿里云 SMS                 | 短信验证码发送       | 仅发送验证码，不存储 |

## 四、社会伦理合规说明

1. **无歧视原则**：本软件的推荐算法不含性别、年龄、种族等歧视性因素，体型分析仅用于服装适配推荐
2. **数据最小化**：仅收集业务必要的数据，用户可拒绝非必要数据收集
3. **透明度**：AI 造型师的推荐理由对用户可见，用户可了解推荐依据
4. **安全防护**：实施 JWT 512-bit 认证、PII 字段加密、API 限流、XSS/CSRF 防护等多层安全机制
5. **内容安全**：AI 生成内容经过安全过滤和审核，不含违法有害信息
