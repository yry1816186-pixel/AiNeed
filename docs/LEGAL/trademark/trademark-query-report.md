## 五、查询方法备注

1. **中国商标网**：https://wcjs.sbj.cnipa.gov.cn （需注册登录）
2. **商标近似查询**：输入商标名称 + 选择国际分类号
3. **盲查期风险**：提交后 3-6 个月内的申请无法检索到
4. **建议委托专业代理机构**进行深度检索和申请，降低驳回风险
