## 三、申请流程

### 3.1 在线申请步骤

1. 登录中国商标网网上服务系统：https://sbj.cnipa.gov.cn
2. 注册账户并完成实名认证
3. 选择"商标注册申请"
4. 填写商标信息（名称、图样、类别）
5. 添加商品/服务项目（**注意：只填名称，不填编码**）
6. 上传商标图样（300×300 PNG）
7. 填写申请人信息
8. 提交并缴费（300 元/类）

### 3.2 审查流程

```
提交申请 → 形式审查（1-2月） → 实质审查（6-9月） → 初审公告（3月） → 注册公告 → 颁发证书
```

### 3.3 时间预估

| 阶段     | 时间              |
| -------- | ----------------- |
| 形式审查 | 1-2 个月          |
| 实质审查 | 6-9 个月          |
| 初审公告 | 3 个月            |
| **总计** | **约 10-14 个月** |

## 五、注意事项

1. **商品名称规范**：只填名称，不填编码（如"C090142"），否则会被补正
2. **盲查期风险**：提交后 3-6 个月内的申请无法检索
3. **近似判断**：文字商标需从"形、音、义"综合判断
4. **续展提醒**：注册有效期 10 年，到期前 12 个月需续展
5. **使用证据**：注册后 3 年内需使用，否则可能被撤销
