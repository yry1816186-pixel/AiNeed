## 二、手动查询步骤

### 2.1 推荐查询工具

| 工具             | 网址                     | 适用域名        |
| ---------------- | ------------------------ | --------------- |
| 阿里云万网 WHOIS | https://whois.aliyun.com | 全部            |
| 站长之家 WHOIS   | https://whois.chinaz.com | 全部            |
| ICANN Lookup     | https://lookup.icann.org | .app, .ai, .com |
| CNNIC WHOIS      | https://whois.cnnic.cn   | .cn, .com.cn    |

### 2.2 查询操作

1. 打开上述任一 WHOIS 查询工具
2. 输入域名（如 `xuno.app`，不含 www 和 http）
3. 点击查询
4. 查看结果：
   - **"未找到记录"** → 域名可注册
   - **显示注册信息** → 域名已被注册，查看注册人和到期时间

### 2.3 批量查询命令（需安装 whois 工具）

```bash
# Windows (PowerShell) - 使用nslookup初步检查
nslookup xuno.app
nslookup xuno.com.cn
nslookup xuno.cn
nslookup xuno.ai
nslookup xunoshang.com
```

## 四、域名注册注意事项

### 4.1 实名认证

- .cn / .com.cn 域名必须完成 CNNIC 实名认证
- 需提交营业执照副本扫描件
- 认证审核通常 1-3 个工作日

### 4.2 ICP 备案

- 使用国内服务器的域名需完成 ICP 备案
- .cn / .com.cn 域名无论是否使用国内服务器都需实名认证
- 备案流程约 10-20 个工作日

### 4.3 DNS 配置建议

| 记录类型 | 主机记录 | 记录值       | 用途     |
| -------- | -------- | ------------ | -------- |
| A        | @        | 服务器 IP    | 主站     |
| A        | www      | 服务器 IP    | www 跳转 |
| CNAME    | api      | 后端服务域名 | API 服务 |
| MX       | @        | 邮件服务     | 企业邮箱 |
| TXT      | @        | SPF 记录     | 邮件防伪 |

### 4.4 域名保护策略

1. **多后缀注册**：同时注册 .app / .com.cn / .cn / .ai 防止抢注
2. **自动续费**：开启自动续费避免域名过期
3. **隐私保护**：启用 WHOIS 隐私保护服务
4. **DNSSEC**：启用 DNSSEC 防止 DNS 劫持
5. **域名锁定**：注册后开启域名转移锁定
