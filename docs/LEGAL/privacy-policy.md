# XUNO（寻裳）隐私政策

**版本：V2.0**
**生效日期：2026 年 4 月 23 日**

---

我们非常重视您的隐私保护和个人信息安全。本隐私政策说明我们如何收集、使用、存储、共享和保护您的个人信息，以及您如何管理您的个人信息。

请您在使用 XUNO（寻裳）服务前，仔细阅读并充分理解本政策。使用我们的服务即表示您同意本隐私政策的内容。

---

## 一、我们收集的信息

### 1.1 您主动提供的信息

| 信息类型 | 具体内容                     | 收集目的                     | 同意方式           |
| -------- | ---------------------------- | ---------------------------- | ------------------ |
| 账户信息 | 姓名/昵称、邮箱、手机号码    | 注册与身份验证               | 注册时一次性同意   |
| 身体数据 | 性别、身高、体重、身材类型   | 穿搭推荐与体型分析           | 服务引导时逐项同意 |
| 照片     | 全身照、半身照、面部照片     | 虚拟试穿、色彩分析、体型分析 | **单独弹窗同意**   |
| 偏好数据 | 风格偏好、颜色偏好、场合需求 | 个性化推荐                   | 服务引导时逐项同意 |
| 支付信息 | 支付方式（由第三方处理）     | 订阅与购买                   | 支付时同意         |

### 1.2 自动收集的信息

| 信息类型 | 具体内容                               | 收集目的           | 同意方式       |
| -------- | -------------------------------------- | ------------------ | -------------- |
| 设备信息 | 设备型号、操作系统版本、唯一设备标识符 | 服务适配与安全     | 首次启动时告知 |
| 使用数据 | 访问记录、操作行为、功能使用情况       | 服务优化与改进     | 首次启动时告知 |
| 日志信息 | IP 地址、访问时间、请求 URL            | 安全防护与故障排查 | 首次启动时告知 |

### 1.3 可选收集的信息

| 信息类型  | 具体内容             | 收集目的     | 同意方式       |
| --------- | -------------------- | ------------ | -------------- |
| 位置信息  | 大致地理位置（省级） | 天气适配推荐 | **需用户授权** |
| 通讯录    | 无                   | —            | 不收集         |
| 短信/通话 | 无                   | —            | 不收集         |

### 1.4 我们不会收集的信息

我们明确承诺**不会**收集以下信息：

- 您的身份证号码
- 您的银行卡号（支付由第三方处理）
- 您的通讯录
- 您的短信或通话记录
- 精确地理位置（仅请求大致位置）

1. 优化推荐算法和 AI 模型
2. 开发新功能和服务
3. 个性化内容展示
4. 使用统计和趋势分析

### 2.3 安全与合规用途

1. 账户管理与身份验证
2. 客户支持与投诉处理
3. 安全防护与欺诈检测
4. 法律法规要求的合规义务

**我们不会出售您的个人信息。**

我们仅在以下情况下共享您的信息：

### 3.4 跨境数据传输说明

我们使用的智谱 AI（GLM）API 服务，其服务器位于**中国境内**。您的照片和文本数据在中国境内处理，不涉及跨境传输。

如未来因业务需要涉及跨境数据传输，我们将：

1. 依法进行安全评估
2. 取得您的单独同意
3. 确保接收方具备同等数据保护水平
4. 遵守《个人信息保护法》关于跨境传输的全部要求

## 四、信息存储与保护

### 4.1 存储位置

- 所有数据存储在**中国境内**的服务器
- 数据库：PostgreSQL 16（中国境内机房）
- 缓存：Redis 7（中国境内机房）
- 对象存储：MinIO（中国境内自托管）

### 4.2 安全措施

| 安全层级 | 具体措施                            |
| -------- | ----------------------------------- |
| 传输安全 | HTTPS/TLS 1.3 加密传输              |
| 存储安全 | PII 字段 AES-256-GCM 加密存储       |
| 访问控制 | 基于角色的权限管理（RBAC）          |
| 认证安全 | JWT 512-bit 密钥 + bcrypt 12 轮哈希 |
| 安全审计 | 操作日志记录与定期审计              |
| 安全头   | Helmet 安全头 + CORS 白名单         |
| 防护     | XSS 防护管道 + CSRF 保护 + API 限流 |

### 4.3 加密字段清单

以下字段使用 AES-256-GCM 加密存储：

- 用户真实姓名
- 手机号码
- 邮箱地址
- 身体测量数据（身高、体重）
- 面部照片路径

### 4.4 数据保留期限

| 数据类型     | 保留期限     | 说明                |
| ------------ | ------------ | ------------------- |
| 账户数据     | 账户存续期间 | 注销后 30 日内删除  |
| 身体数据     | 账户存续期间 | 可随时删除          |
| 照片         | 账户存续期间 | 可随时删除          |
| 使用数据     | 最长 2 年    | 用于服务优化        |
| 日志数据     | 最长 6 个月  | 用于安全审计        |
| 法律要求数据 | 法定最短期限 | 如交易记录保存 5 年 |

## 八、隐私政策更新

### 8.1 更新机制

我们可能不时更新本隐私政策。更新时：

1. 在本页面发布新版本
2. 重大变更将通过平台通知、邮件或短信告知您
3. 继续使用服务视为接受更新后的政策

### 8.2 重大变更定义

以下情况视为重大变更：

- 收集个人信息的目的、方式发生变化
- 共享个人信息的对象发生变化
- 您参与个人信息处理的权利发生变化
- 数据跨境传输情况发生变化

重大变更时，我们将重新征求您的同意。
